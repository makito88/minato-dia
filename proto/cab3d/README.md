# 3D運転席モード 試作（proto/cab3d）

本体（`index.html`・`data/`）とは独立した試作ページです。本体のファイルは読み込みも変更もしていません。

## 起動方法
ES モジュールを使うため、ファイルを直接開く（file://）のではなく、HTTP で配信して開きます。
- GitHub Pages：`<公開URL>/proto/cab3d/`
- 手元：リポジトリのフォルダで `python3 -m http.server` → `http://localhost:8000/proto/cab3d/`

URL パラメータ
- `?s=300` … 視点の位置（m）。画面左上のボタンでも切り替え可
- `?bench=1` … 毎フレーム描画して fps を表示（通常は静止画として必要なときだけ描画）
- `?seed=7` … 街並みの乱数（変えると別の街並み）
- `?look=v1` … 最初の試作／指定なし … v2（プログラムのみ）／`?look=v3` … 美術素材版／`?look=v4` … v3＋道床・道路・ブロック塀・窓の素材／`?look=v5` … v4＋木の種類・外壁の種類・畑の種類・枕木・架線柱・レールのむら／`?look=v6` … v5＋マンションの住戸区画・戸建ての横の壁・汚れと軒の影

## 現在の段階

- 静止画版の見た目の比較（v1〜v6）は、これまでどおり

## 区間モード（?route=cs）
- 線形：これまでの曲線に加え、右 R1200 の曲線を1か所（2060〜2380m）。中央の停止位置を 15m、桜町の停止位置を 3220m とする（仮設定）
- 駅：中央・桜町に相対式ホーム（長さ150m・レール面から1m）、屋根・柱・ベンチ、駅名標（漢字・かな・ローマ字・前後の駅。かなとローマ字は data/ride.json から）、停止位置目標「6」、駅舎の簡単な箱
- 踏切：1720m。線路の上の路面と坂、警報機（十字の板）、遮断かん。列車が450m手前から通過までの間、警報灯が交互に点滅
- 電車の信号機：880m・2300m・2930m
- 走行：▶ で2秒後に発車、0.75m/s²で加速、最高速度（0〜80km/h、初期70）で惰行、残り距離からブレーキをかけて停止位置にぴったり止まる。倍速 ×1/×2/×4、揺れの入り切り、速度・走行距離・残り距離の表示。時間は実時間で進み、画面の速さ（fps）に左右されない
- 軽量化：1300mより遠い区画は描かない。影は6m進むごとに描き直す。止まっている間は画面を描き直さない。木は走ると向きが変わるので、2枚を十字に組む
- 中央→桜町の所要時間は約3分13秒（最高速度70km/h）

## 見た目の改善（v2）
- 陰影：4段のくっきりしたセル陰影 → 8段をなめらかにつないだ陰影（樹木の多角形の角が目立たなくなる）
- 影：影の解像度を 4096 → 2048 にして輪郭をやわらげる。天空光を青みのある色で強め、日陰が黒く沈まないようにする
- 白飛び：露出 1.0 → 0.95、日差しを少し暖色に
- 霞：遠景の霞を少し濃く、空の地平線の色とそろえる
- 色調補正（最後に1回だけ画面全体に）：彩度をわずかに抑える、暗部を青みのある色へ持ち上げる、明るい所をほんのり暖色に、ごく弱い周辺減光
- 道床：角の丸い砕石を1つずつ描いたテクスチャ（灰色に少し茶色）
- 建物の配置・線路の形・カメラ位置は変更なし

## 軽量化（第2段階の前）
- 影は視点が変わったときだけ描き直す（以前は毎フレーム、建物をもう一度描いていた）
- 植え込み・雑草の粒の面数を 1/4 に（法線を球の向きにして丸く見せる）。三角形の総数 約235万 → 約156万
- 建物・線路まわりを 120〜160m 四方の区画に分け、画面に入らない区画は描かない
- 対数深度をやめる（重なる面は polygonOffset でずらしてある）
- 高精細画面での描画の細かさを 2倍 → 1.5倍まで

## 素材ライブラリ（assets/images/cab3d/lib/）
- v5〜v10 で受け取った77枚を、背景を抜いて1つずつに分けたもの（74項目・117ファイル）。一覧は `lib/catalog.json`（元のファイル名との対応つき）
- v5 で使っているもの：木（丸い常緑樹・葉桜・針葉樹）、外壁（モルタル・タイル・濃い色のサイディング）、畑（野菜・キャベツ・田んぼ・休耕地）、コンクリート枕木、架線柱、レール
- 素材の選び分けには、街並みの配置とは別の乱数を使う（配置は v2〜v4 と同じ）
- まだ使っていないもの：建物の正面（アパート・マンション・雑居ビル・学校・商店・倉庫・昭和の家・工事中）、竹やぶ、車・バス・トラック・自転車、すれ違う電車、踏切（警報機・遮断かん）・信号（車・電車）・標識・自販機・電話ボックス・ガードレール・フェンス、公園、川・橋・橋脚・トンネル・擁壁・変電所・タンク・神社
- v10（作り直し）で届いたもの：竹やぶ、車の真横（4台）、遮断かん、電車の信号機、橋脚

## v6（建物ののっぺり感をなくす。素材は v11）
- マンション：ベランダ側を「1住戸×1階」の絵2種類（すっきり／洗濯物・布団）を混ぜて並べる。廊下側は玄関ドアの区画、1階はエントランスと駐輪場、妻側は小窓と雨だれの壁、屋上に設備の絵
- 戸建て：横の壁を、小窓・雨どい・室外機・給湯器の絵に（色はその家の外壁の色に寄せる）
- すべての壁に、雨だれ・下のほうの汚れ・軒の影を掛け合わせで重ねる
- 立体のベランダ・窓は計算だけして捨て、乱数の引き方を v5 と同じにしているので、街並みの配置と v5 の素材の選び分けは変わらない
- 未使用：戸建ての1階正面（house_front_ground）

## 仮設定
- 区間：中央（0km）→ 桜町（3.2km）の途中を想定した仮想区間。駅名・キロ程は本体 index.html の STATIONS を参照し、区間内の線形・街並みは仮
- 狭軌 1,067mm、線路中心間隔 3.8m、自列車は左側の線路
- 線形：直線 → 緩和曲線 → 右 R700 → 緩和曲線 → 直線 → 左 R900
- 運転士の目の高さ：レール面 +2.45m、線路中心から左へ 0.45m

## パフォーマンス（第1段階時点）
- 描画回数（draw call）約30、三角形 約235万（影の描画で同じ量をもう一度描く）
- 測定環境：クラウド上のヘッドレス Chromium・GPU なし（SwiftShader によるソフトウェア描画、2コア）で 1280×720 が 約0.5fps。
  GPU のない環境の値なので、実際の PC の性能の目安にはなりません。実機での測定が必要です
- 課題：住宅・樹木を1つの大きなメッシュにまとめているため、遠くの細部も同じ細かさで描いている。
  第2段階で、遠くの建物の簡略化（LOD）、影を落とす範囲の限定、樹木の面数削減を行う予定
