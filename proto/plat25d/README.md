# 峠駅 ホームの場面（2.5D 試作）

本体とは独立した試作ページです。1枚の背景画の上に、列車の真横の絵を背景画と同じ遠近で貼って動かします。

## 起動方法
HTTP で配信して開きます（file:// では画像を読めません）。
- GitHub Pages：`<公開URL>/proto/plat25d/`
- 手元：リポジトリのフォルダで `python3 -m http.server` → `http://localhost:8000/proto/plat25d/`
- `?t=24` … 場面の時刻（秒）を指定して開く
- `?size=` `?endsize=` … 列車の側面・最後尾の妻面の大きさの倍率（画面のスライダーでも変えられる）。初期値はどちらの絵も 側面 0.77・正面 0.88
- `?train=gpt` … ChatGPT 版の車両の絵で開く／`?train=3d` … 3D の気動車で開く（初期は Gemini 版。画面のボタンでも切り替えられる）

## 仕組み
- 背景画から測った遠近：消失点 (1046, 490)、焦点距離 1810px、目の高さ＝レール面から 1.59m、線路の中心は目から左へ 2.14m
  （遠くまでの2本のレールの交点、レールの間隔、枕木の間隔から求めた。列車は車体の中心を線路の中心にそろえて縮める）
- 列車の側面は、画面の縦の列ごとに「その列に映る奥行き」を求め、絵のその位置を縦に引きのばして描く
- ホームの縁より右下には描かない（列車の足回りがホームに隠れる）
- 最後尾の妻面は、真後ろから描いた絵をその奥行きの大きさに縮めて置く
- 停車位置は、最後尾が目の前 10m（編成全体と妻面が見える位置）
- 木漏れ日（ホームの床の光のまだら）、手前の葉のそよぎ、マウスの動きによる視差
- ダイヤとは未連動。一定時間ごとに「到着 → 停車 → 発車」をくり返す

## 素材（assets/images/plat25d/）
リポジトリ所有者が生成AI（Gemini / ChatGPT）で作成した画像を加工したもの。
- `toge_base.webp` ホームの全景（列車なし）
- `gem_side.webp` `gem_end.webp` 古い気動車2両の真横・真後ろ（Gemini。くすみを少し取るため、鮮やかさとコントラストをわずかに上げた）
- `gpt_side.webp` `gpt_end.webp` 同じく ChatGPT 版（錆が強い）
- 側面の絵は、レール面から屋根まで 3.7m、2両で 42m になるよう横にのばして使う
- `train_side.webp` 最初の試作の電車（現在は未使用）
- `leaves.webp` 手前の葉（マゼンタの背景を抜いたもの）

## 3D の気動車（車両の「3D」ボタン）
- 生成AIで描いた気動車の絵（素材 toge_3d）を、Microsoft TRELLIS で立体にしたもの。assets/models/plat25d/（kiha.bin・kiha.json・kiha.webp）
- 1両を長さ21.3m・幅2.9m・高さ3.9m（屋根の上の機器まで）に合わせ、同じ立体を2両、向かい合わせにつなぐ
- 背景画と同じ遠近（消失点・焦点距離・目の高さ）のカメラで描き、ホームの縁より右下は隠す。大きさは「側面の大きさ」のスライダーで全体を縮める（初期 0.77）
- three.js は 3D運転席の試作（proto/cab3d/lib/）のものを使う
