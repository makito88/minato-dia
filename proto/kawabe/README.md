# 川辺駅 運転指令盤（proto/kawabe/）

川辺駅の番線・信号機・待ち合わせのしくみを見るページ。本体（index.html）とは別。

- core.js：線路図の座標、信号機、30分パターンのダイヤ、信号の色の計算（画面なし）
  - 列車を足す・変える：`PAT` に1行。ent（W 中央方面 / E 港方面 / B 温泉支線）、tr（番線）、ex（出る方向）、arr・dep（毎時の分）
  - 変えたら `node -e "console.log(require('./core.js').check())"` で、進路の重なり・番線の重なり・単線の重なりを確かめる（空の [] ならOK）
- index.html：指令盤の画面とタブ（いまの動き／番線の予定／時刻表／信号のしくみ）
- 駅の形：島式2面4線。1・2番線＝下り（1番線は待避と温泉支線）、3・4番線＝上り（4番線は待避）
- ダイヤは見本。地図のシミュレーションの列車とはつながっていない
