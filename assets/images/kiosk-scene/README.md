# 店内画で買い物を試す素材

2026-11-12、ユーザー添付の「港駅コンビニの忙しい朝 (1).png」を基に画像生成で作成。

- `background.webp`：冷蔵棚左の客を取り除き、隠れていた棚・床を補った背景。他の人物は静止画のまま。
- `walk.webp`：同じ通勤客の後ろ・正面・右・左 × 歩行4姿勢。透明背景。
- `reach.webp`：後ろ向きの、腕を下ろす・半分伸ばす・伸ばす・手を戻す4姿勢。透明背景。
- `frames.json`：各姿勢の切り出し範囲と頭の中心の横位置。足元を基準に配置。

WebPは生成PNGから縮小せず圧縮。描画座標は元の店内画の1628×966に合わせている。
これは4方向の絵を切り替える試作。骨格で連続的に回る3Dモデルや、全員が動く完成版ではない。
生成した姿勢には体格・持ち物の細かな揺れがあり、歩きのなめらかさは次の改善点。
