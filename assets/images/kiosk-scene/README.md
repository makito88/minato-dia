# 店内画で買い物を試す素材

2026-11-12、ユーザー添付の「港駅コンビニの忙しい朝 (1).png」を基に画像生成で作成。

- `background.webp`：冷蔵棚左の客を取り除き、隠れていた棚・床を補った背景。他の人物は静止画のまま。
- `walk.webp`：同じ通勤客の後ろ・正面・右・左 × 歩行4姿勢。透明背景。
- `reach.webp`：後ろ向きの、腕を下ろす・半分伸ばす・伸ばす・手を戻す4姿勢。透明背景。
- `frames.json`：各姿勢の切り出し範囲と頭の中心の横位置。足元を基準に配置。

WebPは生成PNGから縮小せず圧縮。描画座標は元の店内画の1628×966に合わせている。
これは4方向の絵を切り替える試作。骨格で連続的に回る3Dモデルや、全員が動く完成版ではない。
生成した姿勢には体格・持ち物の細かな揺れがあり、歩きのなめらかさは次の改善点。

## 飲み物を持つ歩行（2026-11-12）
- `carry-coffee.webp` / `carry-sports.webp`：商品取得後だけに使う、4方向×4姿勢。缶を握る手と飲み物が一体になった画像。右肘を曲げて胴のそばに保ち、空いている腕と脚は歩く。停止中も同じ素材を使う。
- 画像生成の指定：元の `walk.webp` の人物・服・鞄・画風・4×4配置・脚の姿勢を維持。右手で小さい缶を握り、持つ側の腕を振らずに歩く。透明背景。スポーツドリンク版では同じ位置の飲料を青いラベルにする。

## 会計と退出（2026-11-12）
- `background-checkout.webp`：有人レジ前の静止した男性・鞄・受け渡し中の袋・影を除き、床とカウンターを補った背景。レジの女性は手をカウンターに置く。元の `background.webp` は残す。
- `payment.webp`：2行×4姿勢、上段はコーヒー・下段は青い飲料。足をそろえて立ち、右手で飲料を保ち、左手でカードを出す→かざす→戻す。停止中の後ろ姿にも1姿勢目を使い、歩行コマの片足を上げた状態で待たせない。
- 素材は組み込みの画像生成で作成。背景の指定：「有人レジの男性・袋・影だけを取り除き、店員の手を自然に置く。ほかの人物・商品・構図・光・文字を維持」。支払いの指定：「同じ人物、透明背景、2行4列、背面、右手の缶を動かさず、画像左側の左腕でカードを左上へかざす。体格・足元・鞄を各コマで固定」。生成後に左右の手を確認して修正した。
- PNGからWebPへ画質90で変換。切り出し座標と頭の横中心は `frames.json` の `payment`。カード読み取り機の小さい台と支払い後の点灯はCanvasで描く。

## かごと共通の中身（2026-11-12）
- `basket.webp`：1122×1402、透明背景、4列×5段。後ろ・正面・右・左の4歩行姿勢と、最後の段に背面のカード支払い4姿勢。人物・右手・空かご・持ち手は一枚の絵。中身は `loadout.contents` をCanvasで重ねる。商品の組合せごとの人物画像は作らない。
- 画像生成の指定：`carry-coffee.webp` と `payment.webp` を参照。同じ黒いスーツ・黒い肩掛け鞄・手描きの人物。右手を下げ、落ち着いた緑の空の買い物かごを持つ。かごと指を接触させ、左手は歩行時に自由。各方向の最初の姿勢は両足を接地。最後の4姿勢は左手のカードを出す→かざす→戻す。全身・同じ体格・全20姿勢、透明背景、文字・商品・床・影なし。
- 生成PNGから縮小せずWebP画質90へ変換。`frames.json` の各 `basket` に中身の中心・縁・前面の範囲を追加。前面は元画像から重ね直して中身の下半分を隠す。
- 行の実際の境界は y=0/282/563/832/1106/1402。均等に5分割すると別コマの頭が入り、支払いの頭が欠けるので、画面検証後に切り出しだけを修正。4方向と支払い全20姿勢を描画で確認した。
- かごへ入れる腕は下記の追加素材へ接続。袋詰め・返却の絵は未作成。かごの中身は小さい描画用表現で、商品ラベルの高密度化も残る。

## 棚からかごへ移す左手（2026-11-13）
- `basket-take.webp`：1774×887、透明背景、4列×2段。上段コーヒー・下段スポーツドリンク。右手に空かご、左手を棚へ伸ばす→飲料を握る→かごの内側へ下ろす→手を離す。足元を固定した背面中心の8姿勢。手で持つ飲料は人物と一体、かごに移した品は共通レイヤー。品の組合せ別の画像は増やさない。
- 画像生成の指定：既存 `basket.webp` の人物・黒いスーツ・肩掛け鞄・緑の空かごを維持。全身、同じ高さと接地位置、右手とかごを接触、左手のみで1本を取りかごへ入れる4姿勢、上段は茶色の缶、下段は青い飲料。透明背景・文字・床・影なし。
- 修正指定：両段の3列目だけ、左腕が背中や鞄を横切らないようにする。体と顔を右のかごへ少し回し、腕は腹の前を通って一部が胴に隠れる。握った飲料をかごの縁の内側へ下ろす。他の6姿勢は維持。最終PNGを縮小せずWebP画質90へ変換。
- `frames.json.basketTake` に品別の4姿勢と、各かごの中心・縁・前面を定義。手で保持している間は同じ品をかご内に描かず、手を離した時刻で切り替える。修正後の下ろす／放す姿勢を混載例で画面確認。4姿勢なので中間の曲げ伸ばしは連続補間されない。


## 袋詰めと袋を持った歩行（2026-11-13）
- `bag-pack.webp`：1774×887、2品×4姿勢。透明背景、同じ黒いスーツと鞄の男性、正面寄りの右斜め向き、両足を接地。台に手を伸ばす・飲料を握る・袋の口へ下ろす・手を離す。生成時は台・かご・袋を描かず、腰の高さで手を動かすよう指定。飲料と指は一枚の絵。台とかご・袋の描画位置を実際の指の位置に合わせて調整した。
- `bag-walk.webp`：1122×1105、4方向×4姿勢。既存 `basket.webp` を参照し、かごを短い持ち手の小さなクラフト紙袋へ変更。手と袋は同じ画像、先頭姿勢は両足接地、ほかは歩行。生成された1122×1402の末尾に重複した左向き1段があったので、必要な最初の4段だけを採用した。
- 生成PNGをWebP画質90へ変換。切り出しと頭の横中心は `frames.json` の `bagPack` / `bagWalk`。品の組合せごとに袋歩行の絵は増やさず、中身の状態は配列で保持する。
- 台へかごを下ろす／袋を持ち上げる中間姿勢は未作成。袋詰めの途中は4姿勢の切り替え。台・かご・紙袋のCanvas描画は手描きの背景に対して簡易的で、質感改善が残る。
