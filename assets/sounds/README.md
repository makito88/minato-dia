# 環境音の録音ファイル

利用者（リポジトリ所有者）から提供された録音です。

- 形式：**MP3・128kbps・モノラル**（元の 192kbps ステレオから変換。ゲームは再生時にモノラルで鳴らすため、聞こえ方は変わりません。変換前後で 20kHz までの各帯域の差は 1.4dB 以内）
- 鳴らす場所・音量・間隔などは `data/sounds.json` に書いてあります。音源を足すときは、ここにファイルを置き、`data/sounds.json` に1件書き足してください
- ラウドネス（`lufs`）は `ffmpeg -i ファイル -af ebur128 -f null -` で測った値を書きます
- 元の高音質な録音は、このリポジトリとは別に保管してください
