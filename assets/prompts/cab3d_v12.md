# 3D運転席 素材 v12（試し：画像から3Dの車を1台）

## 使い方
1. 灰色の枠の文章をそのままコピーして、ChatGPT か Gemini に貼り付け、車の絵を1枚作ります
2. その絵を、画像から3Dを作るサイト（Meshy または Tripo）に読み込ませます
   - Meshy：「Image to 3D」を選ぶ → 絵をのせる → 作る → 「Download」で **GLB** を選ぶ
   - Tripo：「Image to 3D」→ 絵をのせる → 作る → ダウンロードで **GLB** を選ぶ
3. 車の絵（png）と GLB の両方を **ピクチャ > `minato-dia素材` > `cab3d_v12`** に保存します
4. 「v12 置いた」と伝えてください。どのサイトで作ったかも教えてください（使える条件の確認と、作者表示のため）

背景は緑ではなく **白** にしています（3Dを作るサイトは、白い背景のほうが形をきれいに取り出せるため）。
