# 新しい地図のタイル：ChatGPT への指示文（段1・2026-11-15）

横に長い新しい地図（`docs/line-plan.md`）の絵を、タイルに分けて ChatGPT に描いてもらうための指示文です。
下絵とタイルの切り抜きは `tools/map-sketch.py` で作り直せます（位置を直したら、もう一度動かすだけ）。

## ファイル
| ファイル | 中身 |
|---|---|
| `sketch.svg` | 下絵（全体・ラベルと凡例つき）。1km＝100マス、x＝中央駅からのキロ×100、本線は y=700 |
| `overview.png` | 下絵の全体図（3100×1000px） |
| `overview-tiles.png` | 全体図にタイルの枠（赤＝本線の帯 m1〜m8、青＝北の帯 n1〜n8）。**つないだ確認用の1枚** |
| `tiles/m2-chuo.png` など | **ChatGPT に渡す下絵の切り抜き**（文字なし）。本線の帯 1024×1536、北の帯 1024×1024 |
| `tiles/m2-chuo-label.png` など | 同じ所の、名前つきの小さい絵（人が見て確かめる用。ChatGPT には渡さない） |
| `style-ref.jpg` | 今の地図の絵の一部（タッチと見下ろす角度のお手本） |
| `tiles.json` | タイルの位置（マスとキロ）と、中にある駅 |

## タイル（1枚＝横4.5km。となりと0.5km以上重なる）
- **本線の帯 m1〜m8**：横4.5km×縦6.75km（y 325〜1000）＝縦長 1024×1536。
- **北の帯 n1〜n8**：横4.5km×縦4.5km（y 0〜450）＝正方形 1024×1024。本線の帯と1.25km重なる。
- 案（line-plan.md）は「本線の帯9枚＋北の帯5〜6枚」でしたが、東の海2.5kmは港のタイルに入るので**本線は8枚**、北は空港・中央の北もうめるため**8枚**にしました（n1・n2 は田んぼと住宅だけなので、いちばんあとでよい）。
- 1枚の大きさは同じ（1024px＝4.5km）なので、絵の縮尺はどのタイルもそろいます。

## 渡す順番（おすすめ）
同じ ChatGPT の会話の中で、続けて頼むと色とタッチがそろいやすいです。

1. **m2 中央**（いちばん大事。ここで「今の地図と同じタッチ」を決める）… 共通の決まり＋`style-ref.jpg`＋`tiles/m2-chuo.png`＋m2 の文
2. **m3 桜町 → m4 大学前 → m5 緑ヶ丘 → m6 川辺 → m7 新田 → m8 港と海**（東へ）… 毎回、共通の決まり（短い形でよい）＋そのタイルの下絵＋**ひとつ前にできた絵**（「左はしの0.5kmはこの絵の右はしと同じ景色につなげて」）
3. **m1 空港**（中央の西）… m2 の絵を「右はしをつなぐ相手」として渡す
4. **n6 森下と峠 → n7 温泉 → n8 山 → n5 川上 → n4 丘と田んぼ → n3 北の田んぼ**… 下にある本線の帯の絵を「下のはしをつなぐ相手」として渡す
5. **n2 中央の北 → n1 空港の北**（あとでよい）

角度や色がずれたら、そのタイルだけ描き直してもらう（何回かやり直す前提）。届いた絵は `tiles/` の名前から `-label` を取り、ファイル名の頭を同じにして（例 `m2-chuo-art.png`）送ってください。次の段で、並べて確かめるページを作ります。

## 全体の共通の決まり（毎回はじめに貼る）

```
架空の日本の地方都市「みなと川沿線」の、上から見た絵地図の一部（タイル）を描いてください。
あとで横にたくさん並べてつなぐので、次の決まりを必ず守ってください。

・添付の「下絵」と同じ位置に、同じものを描く。下絵の形・川・海岸・道・町の広がりの位置をずらさない。
  画像の大きさと縦横の比は下絵と同じ。下絵の四すみは、そのまま絵の四すみ。
・下絵の色の意味：黄緑の細かいマス＝田んぼ、横じま＝棚田、うすい緑＝丘・草地、緑＝森、濃い緑＝山、
  青＝海と川、川ぞいのうすい緑＝河川敷、うすいはだ色＝戸建ての住宅、濃いはだ色＝家と店がこみあう所、
  オレンジ茶＝団地、うす紫＝ビル街、赤みのピンク＝商店・モール、水色＝役所・病院・博物館、
  オレンジ＝学校・大学、灰色＝工場、青灰色＝倉庫、うす灰色＝空港、ピンク＝温泉街、白い線＝大きな道、
  白い四角＝駅舎、茶色の太い線と灰色の点線＝線路の場所。
・見下ろす角度とタッチは、添付の「今の地図」（style-ref）と同じ：高い所から斜めに見下ろす鳥の目の絵地図。
  建物は小さな立体で、南側（画面の下側）の壁が少し見える。やわらかい水彩とアニメの背景画のようなタッチ。
・光は左上から。影は右下へ短く。季節は秋の昼（晴れ）。田んぼは黄金色の稲、山の木は少し紅葉。
・線路・レール・電車・駅名・文字・数字・看板の字・地図記号・方角の印・枠・凡例は描かない。
  線路の場所（茶色の線）は、砂利と草の細い帯だけにしておく（あとでゲームが線路を上に描く）。
・車やトラック、人、飛行機も描かない（あとでゲームが描く）。
・画面のはし（四方）は切れたままでよい。はしを白くしたり、ぼかしたり、絵の枠を付けたりしない。
・ほかのタイルとつなぐので、全体の色の明るさ・彩度は「今の地図」とそろえる。
```

続けて2枚目からは、短い形でよい：

```
さっきと同じ決まり（角度・タッチ・秋の昼・左上の光・線路や文字や乗り物は描かない・四方は切れたまま）で、
次のタイルを描いてください。添付の1枚目は下絵、2枚目はとなりのタイルの完成した絵です。
（となりの絵と重なる、はしの0.5km（画像の幅の約11%）は、となりの絵と同じ景色・同じ色になるようにつなげてください。）
```

## タイル別の文

数は「町のカルテ」（`docs/machi-karte.html`）の**駅から1km圏**の数（すべて架空・仮）。絵は「雰囲気で合う」でよく、数そのものは町のカルテが正です。中のかっこは、前回見つけた「絵と町の話のずれ」の直しです。

### m1 空港（中央駅の西 7〜2.5km）
```
このタイルは、町の西のはずれの地方空港です。
・下絵のうす灰色の中に、南北にまっすぐな滑走路（長さ2,500m・タイルの縦のほぼ1/3強）と、平行な誘導路、
  エプロン（飛行機はなし）、小さめの旅客ターミナルビル（2〜3階）を描く。
・ターミナルの東に、平らな駐車場・空港ホテル（7〜8階）・レンタカーの営業所・物流の倉庫を数棟。
・空港のまわりは田んぼと、ところどころに住宅のかたまり。滑走路の北と南の延長の上には高い建物を置かない。
・南のはしは海（入り江）。滑走路の南は海の上へ飛行機が出ていく形。
・点線の場所には他社の線路の細い帯と、空港駅の小さな駅舎（屋根つきのホーム1本分）だけ。
```

### m2 中央（中央駅の西3km〜東1.5km）
```
このタイルは、県庁所在地の中心「中央駅」のまわりです（1日に約5万7千人が乗る大きなターミナル）。
・うす紫の所はビル街。ただし近くに空港があるので、ビルは高くても20階くらいまで。高い塔やタワーは描かない。
  オフィスビルが約260棟、マンション約85棟、ホテル18軒。夜の飲み屋街もある繁華な街。
・駅ビル（大きな百貨店つき）と、駅の南の駅前に大きなバスターミナル（屋根つきの乗り場がいくつも並ぶ）、
  タクシー乗り場、立体駐車場（何棟か。合わせて6,500台くらい）。
・駅の北に県庁と市役所の大きな庁舎（広場つき）、北東に県立図書館と県立美術館。
・駅の南東にアーケードの商店街（長い屋根の通り）。
・駅の西（左）の線路の北側に、電車の車庫（何本も並んだ線路の場所・細長い屋根の検査庫1棟）。
  車庫の線路の場所は砂利の帯だけ。電車は描かない。
・南を通る点線の場所は他社の線路（細い砂利の帯と、中央駅の南の小さめの駅舎）。
・まわりは家と店がこみあう住宅地、その外は田んぼと丘。
```

## 数字の出どころ
- 駅の横の位置（キロ×100）：index.html の `ST` の km（**内**：ゲームの決まり。変えていない）。
- 支線の駅の位置：今の地図の向きを 100マス/km に広げたもの（**仮**）。
- 空港・車庫・大学・団地・モール・城跡・田んぼ・高校の位置、川と海岸の形：この下絵で決めた（**仮**・すべて架空）。
- 施設の数：町のカルテ（**仮**・架空）。
