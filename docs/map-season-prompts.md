# 地図の季節の絵：ChatGPT などに描いてもらう頼み方（やり方B）

2026-11-16（第10回）。いまのゲームの地図は、夏の絵（`assets/images/map_bg.webp`・2000×840）から、**計算で色を変えて**季節を出しています（やり方A）。
同じ構図で描いた **春・秋・冬の絵** を置くと、その季節はその絵を使います（日ごとに少しずつ混ぜて切りかわる）。雪の日の雪・桜と梅の花・山の上の雪・夜の光は、絵の上に今までどおり重なります。

## 置く場所とファイル名

| 季節 | ファイル | いつ使うか（data/map-season.json の `art.peak`） |
|---|---|---|
| 春（新緑） | `assets/images/season/map_bg_spring.webp` | 4月はじめから少しずつ、4月末〜5月が中心、6月なかばで夏の絵へ |
| 秋（紅葉） | `assets/images/season/map_bg_autumn.webp` | 10月なかばから、11月が中心、12月はじめで冬へ |
| 冬（葉の落ちた木・枯れ草・雪のない冬） | `assets/images/season/map_bg_winter.webp` | 12月はじめから、1〜2月が中心、3月末で春へ |

- 大きさは **2000×840**（今の絵と同じ）。ちがう大きさでも読めますが、横長の比（2.38:1）は同じにしてください。PNG や JPG でもよく、名前を変えたら `data/map-season.json` の `art.files` も直します。
- 絵がないファイルは、今までどおり計算で作ります（1枚だけ置いてもよい）。
- 冬の絵には **雪を描かない** でください（雪は天気で積もったり解けたりするので、計算で重ねます）。山の上の白さも計算で重ねます。

## 頼み方（そのまま貼れる例）

最初に、今の絵（`assets/images/map_bg.webp` を PNG にしたもの）を添付してから、次のように頼みます。

### 共通の前置き
```
添付した画像は、ゲームの地図の絵（真上から少しななめに見た水彩風のイラスト）です。
この絵とまったく同じ構図・同じ大きさ（横2000×縦840）で、季節だけを変えた絵を描いてください。
・川・海・道・線路・建物・畑の区切り・山の形・橋・港の位置は、1ピクセルも動かさない（あとで重ねて切りかえるため）
・新しいものを足さない・消さない。文字・記号・人・乗り物は描かない
・タッチと明るさは元の絵と同じ水彩風。全体を暗くしたり、白くかすませたりしない
```

### 春（新緑）
```
季節は4月の終わり〜5月はじめにしてください。
・山と林の広葉樹は、明るい黄緑の新緑（やわらかい若葉の色）。杉やひのきなどの針葉樹は今の濃い緑のまま
・田んぼは水を張ったところ（空の色を映した水色）と、まだ土のところ（明るい茶色）が混ざっている。ところどころ、れんげ畑のうすいピンク
・川沿いの桜は葉桜（花は散って、明るい緑）
・芝生や野原はみずみずしい若草色
```

### 秋（紅葉）
```
季節は11月なかばにしてください。
・山の上のほうは紅葉が終わりかけ（茶色っぽい赤）、中腹がいちばん赤・朱色・黄色に色づいている。ふもとは黄色とだいだいが混ざりはじめ
・杉やひのきなどの針葉樹は緑のまま（紅葉の中に緑がまだらに残る）
・町の街路樹はイチョウの黄色とケヤキのだいだい
・田んぼは稲刈りのあとで、土の色と切り株の明るい黄土色。野原は少し黄ばんだ緑
・空気が澄んだ、あたたかい色合い（くすませない）
```

### 冬（雪のない冬）
```
季節は1月なかばの晴れた日にしてください。雪は描かないでください。
・広葉樹は葉が落ちて、枝の色（うすい茶色〜むらさきがかった灰色）。山は茶色い林の中に針葉樹の濃い緑が点々と残る
・野原・河原・土手は枯れ草のうすいベージュ
・田んぼは土の色と切り株
・町の常緑樹は少し深い緑
・晴れた冬の、すこし青みのある澄んだ光（灰色にくすませない）
```

## 届いたら（Claude がすること）
1. 絵を `assets/images/season/` に上のファイル名で置く（webp にするなら `python3 -c "from PIL import Image; Image.open('秋.png').convert('RGB').resize((2000,840)).save('assets/images/season/map_bg_autumn.webp', quality=88)"`）。
2. 構図がずれていないか、今の絵と重ねて確かめる（半分ずつ切りかえて見る・ずれが大きければ描き直しを頼む）。
3. `docs/season-preview.html`（季節の見本）で日付を動かして見る。ゲームの地図・お絵かき帖の「季節」も同じ絵を使う。
4. 季節の絵どうしの切りかわりの日は `data/map-season.json` の `art.peak`（[始まり, 中心の始まり, 中心の終わり, 終わり]）で変えられます。

※ AI の絵は、道や建物の位置が少しずれやすいです。ずれた絵は、切りかわる途中で二重に見えます。そのときは描き直すか、ずれの少ない季節だけ使ってください。
