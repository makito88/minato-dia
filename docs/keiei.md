# 経営のタブ（2026-11-17・ユーザーの頼み）

経費を引いた利益・乗降客数・満足度を毎日グラフで見て、利益を保守・駅の改良・駅ビルとモール・駅前の住宅などへの投資に回す。

グループ全体のお金の流れ（鉄道＝親会社・売店やセンターや工場や配送会社＝子会社・配当）は `docs/group-money.md`。

## しくみ
- **画面**：index.html の5つ目のタブ「経営」（`js/keiei-view.js`）。計算は `js/keiei-core.js`（DOM なし・`tests/keiei-core.test.cjs`）。設定は `data/keiei.json`。保存は `dia-keiei`（引き継ぎコードに入る）。
- **毎日の記録**：運行日を締めるとき（`ENSEN_UI.dayEnd`）に1行。利益は本体の summarize の `profit`（運賃＋特急料金＋駅ナカの家賃−運転経費−車両経費）。乗降客数は乗車×2。最大400日分。
- **満足度（0〜100・仮）**：82 から、混雑（定員150%をこえる列車に乗った人の割合×60）・待ちきれず帰った人の割合×60・積み残しの割合×100・1分以上遅れて着いた列車の割合×25（指令パネルの「きょうの乱れ」）を引き、（便利さ−1）×30・保守・駅の改良を足す。いまは記録と画面だけで、乗客の計算には返していない。
- **積み立て**：はじめ3億円。毎日「利益×投資に回す割合（はじめ20%・0〜50%）＋事業の収入−保守の予算」がふえる。人件費・借金の返済・配当はまだ計算に入れていないので、残りの割合をそれに使ったとみなす。
- **保守の予算**：けずる（0円・できごと×1.6・満足度−4）／ふつう（150万円／日）／手厚く（350万円／日・できごと×0.55・満足度+2）。積み立てが足りなくなると、けずるになる。
- **投資**（工事の日数のあと、少しずつ効き目が0→1）：
  | 投資 | 費用 | 工事 | 効き目（仮） |
  |---|---|---|---|
  | 駅の改良 | 8,000万円 | 10日 | その駅の乗り降り+2%・満足度（乗る人の多い駅ほど） |
  | 駅ビル・ショッピングモール（中央・川辺・港・大学前） | 9億円 | 45日 | その駅へ買い物+12%・観光+6%、家賃120万円／日 |
  | 駅前の住宅開発（桜町・大学前・緑ヶ丘・川辺・新田・森下） | 4億円 | 60日 | 住む人+6%（通勤・通学・買い物）、家賃45万円／日 |
  | 駅前広場とバスの乗りつぎ | 1.2億円 | 20日 | その駅の乗り降り+3%・満足度 |
  | 観光の宣伝と案内所（港・峠・温泉・桜町） | 6,000万円 | 7日 | その駅へ観光+10% |
- **乗客の計算へ**：橋 `keiei-to-rail`（`data/links.json`・temp・強さ1）。運行日の始め（`ensRefresh`）に倍率 `KFX` を作り、`rateParts` の景気・新しい流れのあと、イベントの上乗せより前に掛ける。投資がなければ、前と同じ。
- **まだ**：交換信号所・待避線・番線・車庫の線・車両の増備（本体のダイヤの計算が番線を数えるようになってから）。満足度を乗客の計算に返すか。人件費などの経費。周辺の人口そのもの（町のカルテの数字）を変えるか。
