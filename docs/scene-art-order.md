# 港駅の店の絵の注文書（ChatGPT に渡す用・2026-11-13）

このファイルを、そのまま ChatGPT に渡してください。1回に1つ（たとえば「1. 人のいない店の背景」だけ）頼むと、うまくいきやすいです。
届いた絵は、下に書いた **ファイル名** で `assets/images/kiosk-scene/` に置くだけで、港駅の店の画面の「動く試作と比べる」に出ます（設定は `data/kiosk-scene.json`。名前を変えたいときは、そこを直します）。

## ChatGPT へのお願い（ここから下を貼る）

ブラウザゲーム「みなと川ダイアリー」の、駅の売店（コンビニのような小さな店）の中のアニメに使う絵を描いてください。
店の名前・人物はすべて架空です。実在の会社のロゴ・商品名・有名なキャラクターは入れないでください。

### みんなに共通の決まり
- **見下ろしの角度と光**：前に描いてもらった店の絵（港駅の売店・斜め上から見た店の中・右下から光が当たる・やわらかいアニメ調）と同じ角度・同じ明るさ・同じ画風にしてください。
- **人物の絵は、背景を透明に**（PNG か WebP の透明）。影は描かない（ゲームが床に影を描きます）。
- **1コマの大きさは、横 256 × 縦 384 ピクセル**。コマは左上から右へ、そのあと次の段へ、すき間なく並べてください。
- **足元の位置をそろえる**：どのコマでも、両足の間の床の点が、コマの **左から 128・上から 368** の位置に来るようにしてください（コマの下の真ん中から 16 ピクセル上）。
- **人物の大きさをそろえる**：どのコマでも、頭のてっぺんから足の裏までが、およそ 300〜330 ピクセル。コマからはみ出さない。
- **同じ人物に見せる**：1人ごとに、最初に「人物の設定の表」（正面・うしろ・横の3つの立ち姿）を1枚作り、そのあとのすべてのコマは、その表と同じ顔・髪型・服の色・持ち物で描いてください。服の色や柄・かばんの形は、コマごとに変えないでください。
- 文字は入れない。

### 1. 人のいない店の背景（いちばん先に）
- ファイル名：`background-empty.webp`
- 大きさ：**横 1628 × 縦 966 ピクセル**（前の店の絵とまったく同じ大きさ）
- 中身：前の店の絵と、**棚・レジ・冷蔵ケース・イートイン・入口と出口・改札口の位置を1ピクセルもずらさずに**、**人だけを消した**絵。お客さん・店員・台車・キャリーケースもなし。棚の品・看板・床の模様はそのまま。
- 位置がずれると、人が棚にめりこみます。前の絵を下にしいて、人のいたところだけを床や棚で描き足してください。

## 届いたら（ユーザーがすること）
1. 絵を、上のファイル名で `assets/images/kiosk-scene/` に置く（GitHub に上げる）。
2. 港駅の店の画面を開き直す。その客層のお客さんが、新しい絵で動きます。「まだ絵がない」の欄から、その名前が消えます。
3. ずれていたら（足が床から浮く・棚にめりこむ・大きさがちがう）、Claude に「○○の絵が届いたので合わせて」と頼んでください。Claude が設定（`data/kiosk-scene.json`）で直します。

## メモ（Claude 用）
- 2026-11-13 ユーザーの指摘から足した絵：店内のゆっくりした歩き（いまの会社員の絵は大股で腕を振る）・セルフレジで払う（いまは手を伸ばす絵で画面にふれる形の代わり）・見回す。`pay-self` と `look` は、届いたら画面のほうも使うようにつなぐ（`look` はまだつないでいない）。
- どの客層をどの人の絵で描くか：`data/kiosk-scene.json` の `people[].ps`。人を増やすときは `people` に1つ足す（`grid` の人はマス目の絵）。
- 背景：`background` の上から順に読めたものを使う。`background-empty.webp` が届くと、そちらに差しかわる。店員の絵（`staff`）は、人のいない背景のときだけ描く。
- 絵がないときの代わり：いちばん上の人（会社員〈男性〉・`frames.json` の切り出し）。飲み物は `carryAs` で缶コーヒーかスポーツドリンクの絵。
- いまの会社員（男性）の絵（walk・reach・carry-coffee・carry-sports・payment）は、ユーザーが前に頼んだ試作から取り出したもので、コマの大きさがそろっていない（`frames.json` の切り出し位置で使う）。
