## ユーザーの指摘（2026-11-11）
1. 汐見屋の動きが遅く見える。
2. 店に入る → 棚の前で止まる → レジへ → レジで止まる → 外へ、のスピードが極端にちがい、不自然。実際の人は店の中を動き回り、迷い、ほかの客から離れ、ほかの客が手に取った物が気になる。
3. レジの店員が暇そうに見える。
4. 買ったら、緑ヶ丘の店と同じように、何を買ったかの吹き出しを出してほしい。
5. お客さん同士が重なる。よけるか、離れた所を歩く。
6. 「店の中に人がいるなら、そこに動作・目的・物語があるはず」。

## 原因（調べたこと）
- `js/minato-store-anim.js` の `legs()`：計算の「店にいた時間」（`stay`・平均約3.5分）から、歩く分を一定の速さで先に取り、**残りを棚の数で等分して止めている**。店を横切るのは約10秒なので、3分あまり棚の前で固まる。
- 改札口 ↔ 店（`PRE`・`POST`）は距離に関係なく決まった分（0.12分・0.18分）なので、遠い人ほど速く見える。
- 人の場所はその時刻だけで決めていて、ほかの人を見ていないので重なる。店員はセルフで呼ばれたときしか動かない。会計の吹き出しがない。

## 考え方（決まったこと）
- **計算が決めること**：だれか（客層）・なぜ来たか（きっかけ `mot`）・何を買ったか・何分いたか。**絵が決めること**：その何分を、どう過ごしたか（「店の中の台本」）。
- 台本は、その人の番号のハッシュで決まる（途中から見ても・何度見ても同じ）。**歩く速さは客層ごとに一定**にして、余った時間は「何かをしている時間」で埋める。1か所に長く立たせない。
- 計算が持っていない出来事（買い物・帰る理由）を、絵が勝手に足さない。足したいものは計算の回（A4・A5）で出来事にする。
- 計算を変える回は、**緑ヶ丘の店では起きないように**し、緑ヶ丘の指紋（`tests/minato-store.test.cjs`）が同じことを確かめる。港駅の店の結果は変わってよい（前と後を HANDOFF に書く）。

## 各回の中身

### A1 歩く速さ・行き来・地元のお店の人（絵）
- 客層ごとの歩く速さ（m/秒に近い値。床の広さ 30㎡・絵の1 ≒ 0.9cm から決める）で、改札口 ↔ 店も **距離÷速さ**。歩き出しと止まる前は少しゆるめる。
- レジのあとに短い動き（財布をしまう・袋を持ち直す）を入れてから、ふつうの速さで出る。
- 「店にいた時間」が歩くだけの時間より短い人は、迷う動きなしで早足（計算の時間は変えない）。
- 地元のお店の人（汐見屋・ハーフェン堂）：お客さんと同じ速さ（台車ぶん少し遅く）。台車から荷物を下ろす → レジで店員と検品・受け取りのサイン → 帰る。ひとことの吹き出し（物語の口ぐせ）。**下ろした品を棚に並べるのは店員**（A3 の店員の台本で描く。いつ棚に出るかは A4 の計算）。

### S1 港駅の店の発注をおまかせに（計算・2026-11-11 ユーザーが選んだ。A2 より先にする）
- **わけ**：港駅の店の発注は「はじめの数のまま」で、毎日変わらない。実際のゲームの港駅の乗客の流れ（晴れの平日）で10日まわすと、おにぎりは発注64個/日・売れた64個・売り切れで逃した約83人/日、サンドは36・36・約43、ドーナツは20・20・約19、グミは60・60・約34。9:00・13:00・18:00 におにぎり9品のうち8〜9品の棚が空（毎日同じ）。10:50 は昼前の便（10:30）の直後なので空は5品ほど。パンは逆に多め。
- **すること（第1段：港駅の店の中だけで閉じる）**：
  - 港駅の店も、締めのたびに売上の記録（`CenterCore.salesRecord` と 19:00 の `preRecord`）を作り、**港駅の店の状態の中**（`dia-kiosk-minato` に新しいキー。`{v:1,...}`・直近30日まで）に残す。
  - 運行日の始めに、その記録から `CenterCore.plan`（緑ヶ丘のおまかせと同じ数の決め方：同じ型の日の売れた数＋売り切れで逃した数・天気と季節・ねらい「中くらい」）で、その日の仕入れ数を決めて `S.order` にする。港駅の店の画面で `data/center.json` も読む（読むのは画面だけ。計算は center-core）。
  - **新しい店は最初からおまかせ**（アイデア帳 18.）。港駅の店の画面に「おまかせ／自分で決める」の切りかえと、ねらい（廃棄を少なく／その間／売り切れを少なく）。新聞・雑誌・たばこは店の数のまま（`routeOf` が direct の品）。地元のお店の品（ワッフル・へしこ）もおまかせの数にしてよい（届く数はお店の作れる数まで＝今の橋のまま）。
  - **`dia-orders`・工場の納品書・センターの倉庫・配送会社の便・お金の流れには、まだ書かない**（書くと工場の作れる数を2店で分けることになり、緑ヶ丘の店の結果が変わるため。2店の「運行日の始め」の順番を決める第2段の宿題のまま）。だから緑ヶ丘の店の結果は変わらない（指紋で確かめる）。
- **確かめ**：tests に、港駅の店の14日（晴れ・雨を混ぜる）で、前（はじめの数のまま）と後（おまかせ）の、品ごとの売り切れで逃した数・廃棄・売上・粗利を比べるテストを足す（後のほうが、おにぎり・サンドの逃した数が大きく減る。廃棄が増えすぎない）。HANDOFF に前と後の表。記録がない最初の数日は、はじめの数のまま（または同じ型の日がそろうまで少しずつ）。
- 絵には触らない（棚の量は計算の在庫を描くだけなので、そのまま変わる）。

### A2 動き方の型・台本・よけ方・かご（絵）
- **動き方の型（5つ）**：まっすぐ／行ったり来たり（となりの2つの棚を2〜3回往復）／ひと回り（ざっと1周し、気になった所で3〜10秒止まる）／ぶらぶら（順番なし・短い立ち止まりを何度も）／連れについていく（先頭のあとを少し離れて）。型は客層・きっかけ・**電車まで何分あるか**（計算の時間帯ごとの立ち止まれる時間 `dwellOf`）で決める。電車まで短い人はまっすぐに寄せる。余った時間は、回る道を長くして使う。
- **おみやげを見る人の半分くらいは、ひと回り**してからおみやげへ。電車まで長く、ふらっと寄った人は、立ち止まらずに見て回る。
- **客層ごと**（多さはすべて仮）：交代で働く人＝ほとんどまっすぐ（朝は早足でおにぎり・缶コーヒー・たばこ／夜勤明けはお弁当の前で少し迷ってロング缶／夜はイートインも）。会社員（男性）＝入る前から決まっていてまっすぐ・スマホを見ながら入る・帰りはビールとつまみの2か所。会社員（女性）＝おにぎりとサンドの棚を**行ったり来たり**多め・手に取ってとなりと見比べて戻す。女子高生＝友だちと連れ立ち、グミ・お菓子・フルーツサンド・写真。男子学生＝まっすぐ（から揚げ棒・エナジー・カップ麺）、友だちといるとぶらぶら。年配の人＝ゆっくりひと回り・値札と表示を読む・有人レジ・座る席。観光客＝おみやげ中心・半分はひと回り・写真。客船の客＝旗のツアーは連れについていく・人だかりならすいた棚から・英語の札の前で止まる。家族連れ＝子どもがお菓子の棚へ走り親が追う・親はおにぎりとお茶をまっすぐ。カップル・友だち＝並んで歩き同じ棚で止まる・片方が手に取った物をのぞく。買い物の人＝新聞と日用品 → ついでにお菓子を少し。
- **時間帯**：朝のラッシュ（6〜9時）はまっすぐが増える／昼（11〜15時）はぶらぶらと行ったり来たり／夜（21時〜）は仕事帰りがゆっくり、お弁当とお酒の前で迷う／客船の日は連れとひと回りが増え、混んだ棚を避ける動きが見える。
- **台本の部品**：手に取る・**同じジャンルのちがう品を手に取って戻し、買った品に変える**（戻す品はその時刻に棚にある品から）・表示を読む（新商品が気になって）・スマホと見比べて写真（SNS）・列を見てレジ前の棚へ（行列が気になって）・前の人が手に取った棚へ少しあとで寄る（前の人につられて＝計算のきっかけと同じ）・値札を見て戻す（見て帰った人：高い）・空いた棚の前できょろきょろ（売り切れ・置いていない）。
- **品ごとに立ち止まる秒数**（ユーザー・2026-11-11「グミの棚で長く悩む人はいない」）：A1 までは、店にいた時間の余りを棚の数で等分しているので、グミの前でも何分も立つ。これをやめ、**ジャンルごとに「立ち止まる秒数の幅」**を決め、その中で番号のハッシュで選ぶ（絵だけの数字・すべて仮。`data/minato-store.json` の `walk.anim.dwell`）。
  - めやす（秒）：グミ・ガム・飴 2〜6／缶コーヒー・エナジー 2〜6／冷たい飲み物・温かい飲み物 3〜10／新聞 2〜5／たばこ・ホット（レジで言う）0／傘 3〜8／スナック 4〜12／おにぎり・パン・ドーナツ 4〜15／サンド 5〜15／カップ麺 5〜15／お弁当・おかず 8〜25（夜は迷って長め）／お酒 5〜15／日用品 5〜20（探す）／雑誌・漫画 10〜60（立ち読み）／おみやげ 15〜60（見比べ・写真）。
  - **客層と急ぎで伸び縮み**：急いでいる人（電車まで短い）は0.5倍、年配の人は1.4倍、観光客・客船の客はおみやげで1.5倍、会社員（女性）はおにぎりとサンドで「行ったり来たり」の分を足す、など（下の客層ごと・動き方の型と合わせる）。新商品が気になった人・見比べる人は「表示を読む」「手に取って戻す」の部品で、その棚だけ長くなる。
  - **余った時間は立ち止まりで埋めない**：品ごとの秒数と歩く分を足しても「店にいた時間」が余るときは、動き方の型（ひと回り・ぶらぶら・ほかの棚をのぞく・おみやげの台・レジ前の棚・雑誌）で使う。どの棚の前でも、決めた秒数の幅をこえて立たない（テストで確かめる）。
  - あとで（計算の回）：「店にいた時間」そのものを、買う品のジャンルの秒数から決める（グミだけの人は短く、おみやげを選ぶ人は長く）。今は計算の `stay` を変えない。
- **立つ場所とよけ方**：棚の前に立てる場所（1つの棚に2〜3か所）。来た順にあいている所を割り当て、なければ少し離れて待つか、ほかの棚を先に見る。通路は左側を歩き、すれちがうときは少しよける。どれも「その時刻に店にいる人」だけから決める（途中から見ても同じ・40人までで重さはほとんど増えない）。
- **レジの列**：並んでいる人はレジのほうを向く（こちらに背中）。
- **かご**：入口の横に置く。**買う品が3点以上ならたいてい持つ**（2点はときどき）。持つのは入ったときか、2〜3か所回って手がいっぱいになったとき。精算のとき店員が受け取ってレジの下に重ねる。何も買わなかった人は入口に戻して帰る。かごを持った人は列でかごを下げて持つ。
- **イートイン**：食べ終わった人の半分くらいがごみ箱に寄ってから出る（番号で決まる）。寄らなかった人の席は、店員が拭きに行く（A3）。

### A3 店員の台本・買ったものの吹き出し（絵）
- **仕事の順番**（ユーザー）：**レジに人が並んだら、何をしていても対応する（いちばん先）**。それ以外は、品出し → 商品の整理 → 発注の作業 → 前出し → テーブル拭き・床のモップ。
- 店員が2人の時間は1人がレジ・1人が売り場。1人の時間は、お客さんが列に向かって歩き出したときにレジへ戻り始める（計算は「レジにはすぐ対応」なので、こうすれば計算とちがわない）。
- 計算から読める仕事：会計（品の数に合わせてバーコードを読む。秒数は計算の `service`）・セルフで呼ばれる・年齢確認（A4 のあとは計算の出来事）・荷物の到着と品出し（地元のお店の荷物も）・ホットスナックを温める・期限の切れた品を下げる。発注の作業は 19:00 の締め切りの前に、レジの奥の端末で。
- あいた時間：前出し・レジ前の棚を整える・かごを入口へ戻す・イートインのテーブル拭きとごみ・客が少ない時間と閉店前のモップ（市場帰りの人の床のしずくのあとも、A6 のあと）。入ってきた人に「いらっしゃいませ」。
- **気配り**（ユーザー・2026-11-11 9:04「現実ではたいてい進んでやる」）：①セルフレジで時間がかかりそうなお客さんを、有人レジに案内する（声をかけて手で示す・お客さんが向きを変える）。②もう1人の店員がレジを離れたら（セルフで呼ばれた・品出し・年齢確認など）、ホットスナックの場所にいた店員が**レジの位置にずれる**。絵では、A4 で計算の出来事になったものを描く（A4 の前は、計算の「呼ばれた時間」だけで、ずれる動きを描いてよい）。
- **買ったものの吹き出し**：緑ヶ丘の店と同じ「＋金額　品・品」に、客層ときっかけの小さな札。会計が終わる時刻に。混んでいる時間は同時に出す数に上限。

### A4 計算1（`js/kiosk-walk.js`・港駅の店の設定だけ）
- **年齢確認**：セルフレジでお酒を買う人は**全員**、店員が呼ばれて確認する（今の「セルフで店員を呼ぶ」と同じしくみ。そのあいだ有人レジが止まる）。今の「お酒の人はセルフを使えない」は港駅の店では外す。**有人レジでの確認は、若く見える客層（学生など）だけ**（会計が少し長い）。
- **気配り**（ユーザー）：ほとんどの店員が持つ性格。強さは今の店員の「接客」（`js/kiosk-staff.js` の `careOf`＝接客の得意×やる気）から決め、**接客がていねい・ふつうの店員はする、そっけない店員とやる気の低い店員はときどき**、とする（数字は仮）。
  - **有人レジへ案内**：セルフで店員を呼ぶことになりそうなお客さん（年配の人・品の多い人・現金の人〔A5 のあと〕・お酒の人）を、レジに並ぶ前に気づいて有人レジへ。**有人レジがすいているときだけ**（混んでいたら案内しない）。案内された人は、セルフで店員を呼ばずにすむ（出来事 `guide`）。
  - **レジに寄る**：店員が2人いる時間に、1人がレジを離れたら（セルフで呼ばれた・年齢確認・品出し）、もう1人がレジに入る。今の「セルフで呼ばれると有人レジが止まる」は、**もう1人がいれば止まらない**（その店員の速さで会計する）。出来事 `cover`。
  - 港駅の店の14日で、セルフで店員を呼んだ回数・有人レジが止まった分・列で帰った人が、前と後でどう変わったかを HANDOFF に。
- **地元のお店の荷物は、店員が並べてから棚に出る**：届いた時刻ではなく、店員が並べ終えた時刻から売れる。店員が忙しいと遅れる（数分）。
- **ごみだけの人**：めったに来ない（**1日に数人**）。買わない。ごみ箱がいっぱいになる早さに効く。
- **ごみのついでに買う人**：ごみを捨てに来た人のうち少し（**1日に数人**）がお菓子の棚に寄って買う。きっかけは「ついでに」。
- 港駅の店の14日の前と後（売上・列で帰った人・セルフの割合・店員を呼んだ回数）を HANDOFF に。
