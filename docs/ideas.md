## おにぎり工場（`factory.html`）

### 1. パンのライン（発酵の時計）　**次にやる**
- **どんなものか**：米のラインの隣に、パンのラインを足します。工程は 仕込み（こねる）→ 一次発酵 → 分割・丸め → ベンチタイム → 成形 → 二次発酵（ホイロ）→ 焼成 → 冷却 → 包装 です。
- **発酵の時計**：パン生地は酵母が生きているので、こね上げの温度と部屋の温度・湿度で膨らむ速さが変わり、**待ってくれません**。オーブンが空かないあいだも膨らみ続け、膨らみすぎ（過発酵：酸っぱい・しぼむ）になります。足りないと固く重いパンになります。米の「浸しすぎ」と同じ形ですが、こちらは止められないのが違いです。
- **決めること**：こね上げの温度（仕込み水の温度で調整）、酵母の量、ホイロの温度、オーブンの台数と焼く順番。
- **見どころ**：生地の箱がふくらんでいく絵、オーブン待ちの列、焼き色。米とパンで人（成形の人数）を取り合います。
- **つながり**：売店のパン（2日もつ）に届きます。おにぎりとは日持ちが違うので、作る時刻の考え方も変わります。

### 2. 人を一人ずつ　まだ
- 夜勤の人に名前・得意な作業・慣れ・疲れ・休憩を持たせます（売店の店員と同じ考え方）。ベテランをどの工程に置くか、休憩をいつ入れるかで朝の出来が変わります。
- **つながり**：終電で来て始発で帰るので、乗客シミュの終電・始発に少し人が増えます。カルテの「ひとりの家計」に工場の人を加えられます。

### 3. 菌と回収（トレーサビリティ）　まだ
- まれに出荷後に「このロットは危ないかも」と分かり、どのトレイがどの駅の売店へ行ったかをたどって回収します。記録をきちんと残しているほど早く、狭く回収できます。
- **つながり**：売店の棚から、その日の品が消えます。

### 4. 売店の注文とつなぐ　まだ
- 売店の20:00の締め切りの仕入れ数を「注文書」として工場へ、工場からは「何が・いくつ・何時に届いたか」の「納品書」だけを返します。売店の計算（`kiosk-core.js`）は変えません。工場を切れば今までどおりの売店にします。
- 工場にとって売店は取引先の一部（たとえば2%）、という背景も持たせます。

### 5. 荷物列車をダイヤから選ぶ　まだ
- 工場を沿線（港の工業地帯など）に置き、始発前や昼の空いた列車に荷物を載せて各駅へ運びます。ダイヤを変えると配送の時刻が変わり、列車が遅れると品出しが遅れます。
- **つながり**：いちばんダイヤとつながる部分です。

### 6. おにぎり1個を追いかける　まだ
- 1個を選ぶと、何時に炊いた米で、どの列車に載り、どの駅の棚に並び、だれが何時に買ったか（または飼料になったか）を追えます。売店の注文とつなぐ・荷物列車ができてから。

### 7. 工場の帯をダイヤグラムの描き方で見る　まだ
- **どんなものか**：「釜ごとの一晩」を、本物のダイヤグラムの描き方でも見られるようにします。縦に工程（洗米・浸漬・炊飯・冷却・待ち・成形）を駅のように並べ、横が時刻、釜ごとに1本の斜めのスジを引きます。
- **見どころ**：冷却が同時に2釜までなのは単線区間、釜で待つのは待避、注文で足した釜は臨時列車、取りやめは運休、4:30の荷物列車は動かせない接続、と同じ形に見えます。夏に冷却が詰まると、スジが寝ていく（待ちが後ろへ伝わる）様子がそのまま見えます。
- **つながり**：スジ屋の見方が、列車以外（米・お客さん・お金）にも使えることを、画面で見せる部分です。

### 8. 構想のつづき（大きいもの）　まだ
- 材料の世界（米は年1回の収穫と倉庫、卵は鶏の年齢で大きさが変わる、小麦は船で港へ、海苔・鮭は海と季節）
- 読みと注文のゆれ（売店の注文の小さなぶれが原料では大きくなる：ブルウィップ効果）
- 味と商品開発（レシピを数字で持ち、試作→試験販売→声→作り直し。原料高で具を減らすか値上げか）
- 廃棄と循環（作りすぎ→飼料→養豚・養鶏→卵が工場へ戻る）
