## おにぎり工場（`factory.html`）

### 決まったこと（設定）
- **場所**：港の工業地帯。歴史の1984年「港の貨物線を廃止。荷物はトラックへ」のあと、空いた貨物線の跡地に建った食品工場「浜手デイリー 港浜工場」（架空）。港に近いので、船で着く小麦や海苔が手に入りやすく、新田の米も遠くない。夜勤の人は港駅・新田駅から通う。中央や温泉の売店までは遠い。
  - 元ネタ：日本では、国鉄の貨物駅や操車場の跡地が、物流センター・工場・商業施設になった例が多い。駅の近くに食品工場がないのも現実どおり（工場はふつう、郊外の幹線道路や高速道路の出入り口の近く）。
- **川辺の配送センター**（2026-10-30 に決定）：川辺駅の周辺に、沿線の売店と小さな店の品をまとめる配送センターを置く。売店からの注文は川辺で店ごとに梱包し、配送する。
  - **なぜ川辺か**：本線と温泉支線の分かれ目で、沿線のほぼ真ん中（線路で中央13.2km・港8.3km・温泉12.9km・緑ヶ丘3.6km・新田4.1km）。カルテでも倉庫・物流施設が6か所ある。10駅のどれを拠点にした場合も、9駅を2台で分けて回る分け方をすべて計算すると、川辺が最も短かった（長い方のトラックで133分、2台で76.0km。道のりは線路と同じ、時速35km、1店15分と仮に置いた）。森下も数字は同じだが、川辺から3.6kmしか離れていないためで、村が小さく山の中なので川辺にした。中央は線のはずれなので最も効率が悪い。
  - **2台の受け持ち**：A＝中央・桜町・大学前・緑ヶ丘・森下（33.6km）、B＝新田・港・峠・温泉（42.4km）。どちらも133分で、時間がそろう。川辺の売店へはセンターから歩いて運ぶ。
  - **時刻**：センターを4:00に出る。Aは最初に中央へ行き（4:25に駅前）、そのあと桜町・大学前・緑ヶ丘・森下を回る（森下が5:45ごろ）。Bは新田・港のあと温泉支線に入る（峠5:26ごろ、温泉5:50ごろ）。売店は6:00に開くので全店に間に合う。峠・温泉は山道で、実際はもっとかかるかもしれない。
  - **ゲームの1日3便とそろう**：売店の朝の便（5:30）・昼前の便（10:30）・午後の便（15:30）と、1時間後に届く臨時便は、川辺のセンターから出ていると考える。
  - **規模**：売店10軒だけでは現実のセンターとしては小さいので、沿線の駅ナカの店、自販機の補充、温泉の旅館や病院の売店などもまとめて受け持つ「沿線の小さな店ぜんぶのセンター」とする。
- **センターに集まる品**（コンビニの配送は温度帯ごとに分けて運ぶのがふつう。センターの中も温度ごとの部屋とトラックが要る）

  - **センターを通らない品**：新聞（新聞社から専用の車で、ほかよりずっと早く。夕刊は午後に別に）、雑誌・漫画（本の問屋＝取次から別の便。発売日が決まっていて、売れ残りは返品）、たばこ（たばこの問屋から週に何回か）。

- **試作に入れたこと**（`data/factory.json` の `deadline`・`ship`）：締め切りを2:30にした。前は「3:30 中央行きトラック（工場から直接）」、その前は「4:30 始発の荷物列車」。締め切りが早まったので、10駅分を受け持つ工場として設備を一回り大きくした（釜4→5、冷却2→3、浸漬タンク12→16）。これで春・秋は試した10夜すべて間に合い（最も遅い夜でも2:08に終わる）、夏は冷却「強」、冬は浸漬125分ほどが要るのは前と同じ。洗米の開始の初期値は18:30。
- **前に考えた案**：工場から中央へ直接トラック（3:30 締め切り）。工場が1つで売店が中央だけなら、こちらが速い。始発電車は、港を4:30ごろに出ても中央に5:10前後で、5:00には少し間に合わない。
- 気をつけること：深夜の駅はシャッターが閉まっていて、開くのは始発の少し前。おにぎりは冷やしすぎると米が固くなるので、運ぶときは20℃くらいの決まった温度（チルドの弁当・サンドとは別の温度帯）と言われている。

### 1. パンのライン（発酵の時計）　**次にやる**
- **どんなものか**：米のラインの隣に、パンのラインを足します。工程は 仕込み（こねる）→ 一次発酵 → 分割・丸め → ベンチタイム → 成形 → 二次発酵（ホイロ）→ 焼成 → 冷却 → 包装 です。
- **発酵の時計**：パン生地は酵母が生きているので、こね上げの温度と部屋の温度・湿度で膨らむ速さが変わり、**待ってくれません**。オーブンが空かないあいだも膨らみ続け、膨らみすぎ（過発酵：酸っぱい・しぼむ）になります。足りないと固く重いパンになります。米の「浸しすぎ」と同じ形ですが、こちらは止められないのが違いです。
- **決めること**：こね上げの温度（仕込み水の温度で調整）、酵母の量、ホイロの温度、オーブンの台数と焼く順番。
- **見どころ**：生地の箱がふくらんでいく絵、オーブン待ちの列、焼き色。米とパンで人（成形の人数）を取り合います。
- **つながり**：売店のパン（2日もつ）に届きます。おにぎりとは日持ちが違うので、作る時刻の考え方も変わります。

### 2. 人を一人ずつ　まだ
- 夜勤の人に名前・得意な作業・慣れ・疲れ・休憩を持たせます（売店の店員と同じ考え方）。ベテランをどの工程に置くか、休憩をいつ入れるかで朝の出来が変わります。
- **つながり**：終電で来て始発で帰るので、乗客シミュの終電・始発に少し人が増えます。カルテの「ひとりの家計」に工場の人を加えられます。

### 3. 菌と回収（トレーサビリティ）　まだ
- まれに出荷後に「このロットは危ないかも」と分かり、どのトレイがどの駅の売店へ行ったかをたどって回収します。記録をきちんと残しているほど早く、狭く回収できます。
- **つながり**：売店の棚から、その日の品が消えます。

### 4. 売店の注文とつなぐ　まだ
- 売店の20:00の締め切りの仕入れ数を「注文書」として工場へ、工場からは「何が・いくつ・何時に届いたか」の「納品書」だけを返します。売店の計算（`kiosk-core.js`）は変えません。工場を切れば今までどおりの売店にします。
- 工場にとって売店は取引先の一部（たとえば2%）、という背景も持たせます。

### 5. 運び方を選ぶ（トラックと、駅ナカへの最後の区間の電車）　まだ
- **基本はトラック**。上の「決まったこと」の川辺の配送センターから2台で回る形。
- **電車は最後の短い区間だけ**：拠点の川辺駅から（両方向・温泉支線へも出やすい）沿線の駅ナカ売店まで、空いている時間の電車に台車ごと載せる選択肢。駅ナカはトラックを止める場所が少なく、台車で駅の中へ運ぶのが負担なので、そこが減る。かわりに、混む時間は載せられず1本見送ることもあり、ダイヤが遅れると品出しも遅れる。
  - 元ネタ：国鉄は1986年に荷物輸送をやめた（積み下ろしで旅客列車が遅れるのが問題の一つ）。今は新聞を一部の電車で運ぶほか、コンビニの商品を私鉄の電車で駅ナカ店へ運ぶ実証実験がある程度で、トラックが主役。
- **つながり**：ダイヤとつながるのは、駅ナカへの電車の区間と、夜勤の人の通勤。

### 6. おにぎり1個を追いかける　まだ
- 1個を選ぶと、何時に炊いた米で、どの列車に載り、どの駅の棚に並び、だれが何時に買ったか（または飼料になったか）を追えます。売店の注文とつなぐ・運び方を選ぶができてから。

### 7. 工場の帯をダイヤグラムの描き方で見る　まだ
- **どんなものか**：「釜ごとの一晩」を、本物のダイヤグラムの描き方でも見られるようにします。縦に工程（洗米・浸漬・炊飯・冷却・待ち・成形）を駅のように並べ、横が時刻、釜ごとに1本の斜めのスジを引きます。
- **見どころ**：冷却が同時に2釜までなのは単線区間、釜で待つのは待避、注文で足した釜は臨時列車、取りやめは運休、2:30の締め切り（川辺の配送センター行き）は動かせない接続、と同じ形に見えます。夏に冷却が詰まると、スジが寝ていく（待ちが後ろへ伝わる）様子がそのまま見えます。
- **つながり**：スジ屋の見方が、列車以外（米・お客さん・お金）にも使えることを、画面で見せる部分です。

### 8. 構想のつづき（大きいもの）　まだ
- 材料の世界（米は年1回の収穫と倉庫、卵は鶏の年齢で大きさが変わる、小麦は船で港へ、海苔・鮭は海と季節）
- 読みと注文のゆれ（売店の注文の小さなぶれが原料では大きくなる：ブルウィップ効果）
- 味と商品開発（レシピを数字で持ち、試作→試験販売→声→作り直し。原料高で具を減らすか値上げか）
- 廃棄と循環（作りすぎ→飼料→養豚・養鶏→卵が工場へ戻る）

## 売店

### ブランド「にったの雫」　すすめている（印の表示まで）
- **できたこと**（2026-10-30）：`data/kiosk.json` に `brands`（にったの雫：印「雫」・色・説明）。品に `brand` を書くと、棚の絵・値札・商品カード・商品の表・棚割りの選択・売れ行きに印が出る。品は塩むすび（170円）と鯖へしこ（210円）。名前は短いまま。
- **次の段**：印をお客さんの動きに効かせる。印のある品は棚で少し目につきやすい／一度気に入った人はブランドで選ぶ（鮭が売り切れでも同じ印の品を買う）／評価やSNSの評判が同じ印のほかの品にも少し効く／工場が芯の残った米を出した日は、印の品すべての評判が下がる（工場の判断がブランドを通して売店に届く）。
- **その次**：工場の「夕方に決める」に米の種類（ブレンド米／にったの雫）。米代が上がり、作れる数に上限（数量限定）。ラベルに精米の日と炊いた時刻。新米の水加減、ふんわり握り、具も沿線から（港のへしこ・新田の漬物）、駅ごとの売り方、築港記念日の記念おにぎり。物語の軸は「港を築いた技師の堤防の技術が新田の棚田に水を引き、その米を港の工場が夜通し炊いて朝の電車の客に届ける」。


### 13. 缶コーヒー1品の因果カード　まだ

### 14. 棚割りの効き目　まだ
