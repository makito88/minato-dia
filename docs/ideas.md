- **場所**：港の工業地帯。歴史の1984年「港の貨物線を廃止。荷物はトラックへ」のあと、空いた貨物線の跡地に建った食品工場「浜手デイリー 港浜工場」（架空）。港に近いので、船で着く小麦や海苔が手に入りやすく、新田の米も遠くない。夜勤の人は港駅・新田駅から通う。中央や温泉の売店までは遠い。

### 1. パンのライン（発酵の時計）　すすめている（第1段まで）
- **どんなものか**：米のラインの隣に、パンのラインを足します。工程は 仕込み（こねる）→ 一次発酵 → 分割・丸め → ベンチタイム → 成形 → 二次発酵（ホイロ）→ 焼成 → 冷却 → 包装 です。
- **発酵の時計**：パン生地は酵母が生きているので、こね上げの温度と部屋の温度・湿度で膨らむ速さが変わり、**待ってくれません**。オーブンが空かないあいだも膨らみ続け、膨らみすぎ（過発酵：酸っぱい・しぼむ）になります。足りないと固く重いパンになります。米の「浸しすぎ」と同じ形ですが、こちらは止められないのが違いです。
- **決めること**：こね上げの温度（仕込み水の温度で調整）、酵母の量、ホイロの温度、オーブンの台数と焼く順番。
- **見どころ**：生地の箱がふくらんでいく絵、オーブン待ちの列、焼き色。米とパンで人（成形の人数）を取り合います。
- **つながり**：売店のパン（2日もつ）に届きます。おにぎりとは日持ちが違うので、作る時刻の考え方も変わります。
- **できたこと**（2026-10-31、`factory.html` の「パンのライン」・`data/factory.json` の `bread`・`js/bread-core.js`・`js/bread-view.js`）：
  - 売店のパン5品。仕込み→一次発酵→分割・丸め→ベンチ→成形（人）→ホイロ→焼成（オーブン1回100個・カレーパンはフライヤー）→粗熱取り（30℃まで）→包装。
  - 発酵の進み（ちょうどよい＝1）が生地の温度で進む。焼く番を待つあいだもホイロで進み、1.15をこえると減点、1.6でしぼむ。
  - 決めること：仕込みの開始・仕込みの間隔・オーブンの台数・こね上げの温度（仕込み水の式つき）・酵母・一次の時間・ホイロの温度と時間・成形の人数。
  - 春・秋20夜で足りない夜：初期値1・冬1・夏3（冷めにくい）・オーブン1台20・間隔30分20。計算で数えただけ。
- **まだのこと**：米とパンで成形の人を取り合う（米のラインの休憩の交代をパンの成形から回す、など）／売店の注文とつなぐ（2日もつので前の夜の残りを引く）／ドーナツの拡張（下の1-4.）／冷蔵して発酵を止める（ドウコン）／焼き色とオーブンの温度。
