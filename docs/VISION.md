# めざす方向（2026-11-06 ユーザーと決めたこと）

## 何を作るか
今の現実の社会を出発点にして、**そこから少し先の未来が見えるシミュレーション**を作る。
人口の減少、EC、AI、自動化、電気自動車、鉄道の使われ方の変化。現実に起きていることが、街・産業・人々の暮らしにどう届くのかを見る。

- **未来の結果は先に決めない。** 鉄道・工場・売店・物流・住宅・住民が、それぞれの事情で動く。互いに影響し合った結果として、予想していなかった変化も生まれるようにする。
- **中心の島は作らない。** 売店も、鉄道も、ほかの島と同じ「島の一つ」。

## 島と橋
- **島**：鉄道（地図・運行）、売店、工場、配送センター（物流）、指令センター、アンケート（住民の暮らし）、路線のお絵かき帖、これから住宅・住民など。
- 島は**ひとりでも動く**。ほかの島とのつながりが「未接続」でも、こわれずに遊べる。
- 島どうしは**中身を直接読まない**。島が外に出すのは、決めた少しの数字だけ（例：売店→「その日の客数」）。受け取る側は、その数字だけを使う。
- **橋**（島どうしのつながり）は一覧にして、それぞれに「実装済み／仮の数値／未接続／廃止」を書く（`data/links.json`。2026-11-09 に作った。トップの「きょうの沿線」→「島をつなぐ橋」でも見られる）。
- 出来事は、ゲーム内の時刻の順に処理する（`docs/START.md` の「因果と時刻の順」を守る）。

## 数字の出どころを3つに分ける
数字には、どこから来たかを付ける。データでは `src` に書き、画面では小さな印で見分けられるようにする。

| 印 | `src` | 意味 | 例 |
|---|---|---|---|
| 現 | `real` | 現実から取り入れた数字（出典を書く） | 立川の天気、祝日、テレワーク 24.6%（国交省 R6） |
| 仮 | `assume` | 仮に決めた数字（あとで変えてよい） | 駅の性格、店の売れ方の係数、時代の流れの曲線の形 |
| 内 | `game` | ゲームの中で生まれた結果 | 売店の売上、乗った人の数、アンケートの答え |

- `assume` を `real` のように見せない。出典がないものは `assume`。
- `game` の結果を、別の島が受け取ったときも `game` のまま（出どころを消さない）。

## 少しずつ、軽く
- 橋は **1回に1本ずつ**かける。かける前と後で、負荷（`?perf=1`・`tools/perfcmp.py`）と結果を比べる。問題があれば戻せる形にする。
- 島の間でやりとりする数字は、**1日に数個**から始める。毎秒は計算しない。
- 情報を全部見せない。プレイヤーは見たい島だけを開けばよい。
- 新しい案は「どの島の、どの数字を動かすか」と「その数字の出どころ（現・仮・内）」を決めてから入れる。決まらないものは `docs/ideas.md` で待つ。

## 橋の約束（2026-11-09 から）
- **形**：`data/links.json` の1本ごとに、`id`（一度決めたら変えない）・`from`・`to`・`values:[{name, unit, src}]`（渡す数字の名前・単位・出どころ）・`state`（`done` 実装済み／`temp` 仮の数値／`none` 未接続／`retired` 廃止）・`strength`（強さ。0 でつなぐ前と同じ）・`read`（いつ読むか：`when`＝`dayStart` 運行日の始め／`after` 何かが確定したあと、`at`＝確定した時刻〈ゲーム内の分〉）・`desc`。やめる橋は消さずに `retired`。
- **一方向・時刻の順**：受け取るのは、受け取る時刻より前に確定した数字だけ。同じ時刻・同じ日の中で読み合う輪は作らない。両方向に効くときは、片方を「前の日（もっと前の時刻）の確定した結果」にする。渡す数字は `{day, t, value}` にできる形（t は確定した時刻。例：工場が 8:00 に出荷を確定 → 10:00 に売店に到着 → 12:00 から販売）。
- **効き目は保存しない**：倍率・補正は、決まった乱数とその日の条件から毎回作り直す。保存には入れない。強さを変えたら、すぐ新しい決まりで計算される。
- **入口は1か所**：受け取る島の計算には、効き目を受け取る入口を1か所だけ足す（売店は `ctx.fx`）。乱数の種と引き方は変えない。つなぎの本体は `js/links/<from>-to-<to>.js` の小さなファイル1つ。
- **新しい保存には `v`**：新しく作る dia- のキーや保存の形には、最初から版の番号を入れる。
