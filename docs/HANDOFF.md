## このチャットで作ったもの（主なもの）
**売店**
- 気分（買ったきっかけ：なんとなく・前の人につられて・行列・SNS・新商品・雨・いつもの・発売日）と、日ごとのジャンル別の気分のぶれ（`mood`）
- 売れ行きの絞り込み（種類・客層・きっかけ・ジャンル・商品・理由・評価・点数・時間帯）、集計、CSV保存
- 売り切れで逃した数を隠す（`hideLost`）
- ホットスナックは売れそうな数だけ温める（時間帯ごとの売れ方を `state.hotF` に覚える）
- 店員を一人ずつ（`crew`）：シフト表（平日・土曜・日曜祝日×朝・昼・夕方・夜）、時給、やる気、慣れ、昇給の相談、辞める、募集と採用、おまかせシフト。人件費＝シフト×時給（22時から割増）。だれもいない時間は閉店
- 万引きの疑い（`shrink`）：品出しで「数が合わない」と気づく。駅（町の犯罪率）・場所・時間・店員の人数・混み具合で変わる。防犯ミラー・カメラ・声かけ（次の日から）
- かご（`basket`）：相性のある組み合わせ（パン＋コーヒーなど）・ついでの品・2つ買い。客単価・点数・一緒に買われた組み合わせ（相性＝たまたまの何倍、定番・似た品・意外）
- 仕入れ数の＋−を押してもボタンがずれない
- 締めの記録 `hist` に店員ごとの稼ぎ（`crew:[[id,円,時間]]`）と人件費を残す（カルテの「売店の店員」が読む）

**リサーチ**：レポートから「この場所に売店を出す」へ

**トップページ**（`js/top.js`）：世界・澪洲国・沿線・店舗・従業員の5つのレイヤー。開いたときに表示（「次から出さない」あり）。上の帯の「トップ」で戻れる

**街のカルテ**（すべて架空、元ネタは現実）
- 市町村：住み心地（架空アンケート）・電鉄の利用率・犯罪率と交通事故率（全国の目安つき）・「電車をよく使う町ほど通勤の満足は高い？」の図
- お金の流れ：いちばん上に「ひとりの家計から見るお金の流れ」（1か月分。モデルの人／売店の店員＝ゲームの保存データから／自分の家計＝ブラウザの中だけ `karte-kakei-m`）。その下に町どうしの流れ、「港の荷主をのぞく」（どこから→何に→どこへ・港の会社6社・もしも4つ）
- 歴史：1885〜2026。日本の地方鉄道とオランダの港町に似せた年表、姉妹港ヴェステルハーフェン、年ごとの路線・人口・乗客、教科書風の挿絵6枚
- 名所・名産・人物：30枚のカード（建物8・街並み6・名産8・人物8）。駅・歴史と行き来できる
- 画像：湯ノ谷・峠の鉄橋・赤レンガ倉庫・名産品（AIの雑誌風。左ページの文字は飾り）、沿線おさんぽマップ、世界地図、澪洲国の地図（北を切り落とした版）

## 2026-10-31 のチャットで作ったもの
**売店の移転**（4200f8b）
- 売店を中央から **緑ヶ丘駅の改札外（駅前）** に移せるようにした。お金のタブの「移転」カード（`moveCard`）で駅と場所を選ぶ（初期は緑ヶ丘・改札外）。次の運行日から移る（`S.moveNext={day,st,place}`、締めのときに適用）。
- 棚割り・品物・店員・在庫は持っていく。値段は初期値に戻り、常連・評判・ホットスナックの覚え（`hotF`）・客の時間の覚え（`custH`）は消える。記録は `state.moves`。
- いっしょに移る店員は、時給＋50円（`wageNext`・昇給の希望 `ask` も）、交通費（往復＝`fare(家の駅,新しい駅)`×2、中央→緑ヶ丘は片道340円）、社会保険（会社15.5%・本人15%。時給＋交通費に掛ける仮の率）。店員の家（`p.home`）は元の駅にする。
- 場所 `soto`（改札外・駅前）を `data/research.json` に足した（地元の客1.0、家賃の率0.1、最低12,000円）。万引きの場所の倍率は1.3。
- 値段を2026年の駅ナカのコンビニの目安に変えた（`priceV:2`。古い保存は読みこみ時に `migratePrices` で直し、ニュースに出す）。たとえば鮭おにぎり220円、ツナ185円、雫の塩むすび240円、鯖へしこ280円、お茶200円、缶コーヒー160円。原価も同じ割合で上げた。
- 損益に「交通費」「社会保険」の行。カルテの「売店の店員」は手取り（社会保険を引いた額）と交通費で家計を出す。
- 設定は `data/kiosk.json` の `move`・`priceNote`・`priceOld`。

**おにぎり工場：機械のライン**（729e7be）
- ユーザーから「手作業ラインは不要」。成形・包装を **機械のライン2本（A・B）を4人で回す** 形に置きかえた（ユーザーが見せた実在の機械の動画が参考。名前は出さず一般的な呼び名にしている）。
- 流れ：シート成形 → 巻き成形 → 塩振り → 包装機（海苔フィルム） → ラベル → 検品 → 急冷 → 段積み。1本1分60個（仮）。
- 止まり方：具の切り替えと表示の直しは2本とも止める。詰まり・フィルム切れ・重さのずれ・金属の反応は、そのラインだけ止まる。
- 4人（ほかに釜番1人）：ラインの係（青、具のタンク・掃除・重さのずれ）、包装の係（橙、フィルム1,000枚・残り120枚でランプ・詰まり）、検品・段積みの係（灰、10箱ごとに運ぶ）、品質管理（青緑、温度の記録・抜き取り・表示の確認）。休憩は1人45分ずつずらす。交代の人がいないと、詰まり・フィルム・重さの対応が遅れ、抜き取りは見送り。
- 夕方の計画から「具入れの人数」「機械の番」を外した。機械の費用は一晩38,000円（根拠のない仮の数字）。
- 春・秋20夜の計算：足りない夜は初期値で1夜（前は3夜）、交代なしで1夜（フィルム切れ2回）、表示の確認を省くと5夜、夏7夜、冬0夜。ラインは一晩67分ほどしか動かず、詰まるところは「浸した米が釜を待つ」と「冷却」に移った。1個あたり約63円。
- 2本が同じ具を作るのは試作の単純化（実際は別の具のこともある）。
- コード：`js/factory-core.js`（`ROLES`・`lineCap`・`lstop[l]`・`fixDrift`・ラインごとの集計）、`js/factory-view.js`（2本のベルト・人の色 `ROLE_COLOR`・時計「ラインの時計」）。

## これからの方針（ユーザーの考え）
- 「Aを起点にしたB」：創造性を重視した架空世界。ただし発端は現実世界。架空の要素ごとに「元ネタ（現実の事実・出典・時点）」と「どう変えたか」をたどれるようにしたい。
- 構想「世界の因果地図」：世界→国→沿線→店舗（＋従業員）。現実・推定・創作を混同しない。原因は、架空世界の中で「条件を1つ変えて同じ日を計算し直す」差で示すのが正直。
- 規模に気をつける（ユーザーは「全部は無理」と感じたことがある）。新しく足すものは「ダイヤ（沿線）とどうつながるか」を一言で言えるものに絞る。

## おにぎり工場（2026-10-30 に追加）
- 構想は「一晩で街の朝ごはんを作る工場」。材料・人・菌・お客さんにそれぞれの時計がある、のが芯。全体の構想：材料の世界（米・卵・小麦・海苔）→工場（米とパンのライン）→人（夜勤）→品質と安全（菌・回収とトレーサビリティ）→読みと注文（ブルウィップ効果）→味と商品開発→廃棄と循環（飼料→養鶏→卵）。
- 場所は港の工業地帯（貨物線の跡地）。出荷は川辺の配送センター経由で、2:30 包装の締め切り → 5:00 中央の売店に並ぶ（時刻表はアイデア帳の「決まったこと」）。
- 今あるのは米のラインだけ（第1段）。成形・包装は機械のライン2本・4人（上の 2026-10-31 を参照）。売店・電鉄とはまだつないでいない。つなぐときは「注文書（20:00の締め）」と「納品書（何が・いくつ・何時）」だけにし、売店の計算は変えない方針。
- 次の候補はアイデア帳（`docs/ideas.md`）の「おにぎり工場」。
