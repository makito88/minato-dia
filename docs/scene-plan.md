# 港駅の店内アニメ（絵の試作）を、できたところから動かす（2026-11-13 ユーザーと決めた計画）

## もとになるもの
- `docs/ref/kiosk-scene-demo.html`：ユーザーが ChatGPT に作ってもらった試作（1ファイル・1.8MB・絵は webp 6枚を中に埋めこみ）。港駅の店（完成イメージ `assets/images/minato-store-concept.webp` と同じ 1628×966 の絵）で、**会社員1人**が飲み物を1本買う流れ（棚へ→手を伸ばす→持つ→有人レジでカード払い→出口）。中の設定：`data/kiosk-scene.json`（棚の位置・通り道・レジ・隠す前の物 occluders・速さ）、`data/kiosk-scene-recording.json`（例の買いの記録・ユーザーの保存ではない）、`assets/images/kiosk-scene/frames.json`（歩く16コマ・手を伸ばす4コマ…の切り出し位置と足元 anchor）。見方は「反応を試す」と「この店の記録を見る（KioskCore の buy の記録どおり）」。
- ユーザーの考え：絵は ChatGPT（生成AI）にまかせ、Claude が手直しとつなぎ。完成まで長い（ChatGPT は3か月以上と言った）ので、ひまなときに少しずつ、変化があればよい。**それまで、できたところだけ動かして、今のアニメと並べてくらべたい。**

## Claude の評価（2026-11-13・ヘッドレスで動かした）
- よい：絵の質・カメラが追う・歩き16コマ・記録どおりに動く作り。軽い（PC 約8%・スマホ相当 約10%・読み込み 約1.5秒・エラーなし）。
- 気になる：動くのは1人だけで、ほかの客と店員は背景に描きこまれて止まったまま（客が何人も動くと目立つ → **人のいない背景**が要る）。会計のとき、カウンターから少し離れて立つ。品は飲み物2種だけ。1ファイルにまとまっていて、ゲームの本当の記録を読むにはつなぎ直しが要る。
- 計算がもう持っている数（お客さん1人ごと）：来た時刻・並んだ時間・会計の始まり・買った品と数・金額・客の種類（14）・有人かセルフか（lane）・対応した店員（by）・常連・イートイン（em）・品切れで買えなかった（look と why）・店員の作業（restock・cook）・配送の到着。**ない**：棚を回る順・品を取る時刻・払い方（現金/カード/スマホ）・レジで1品ずつの時間 → 表示用に、決まった乱数と仮の数で作る（計算は変えない）。払い方は駅のキャッシュレスの割合（アンケート）から。
- いちばんの壁は絵の数（客の種類×動き）。2〜3人にしぼって色ちがいで増やす。

## 進め方
1. **並べてくらべる**：港駅の店の画面の「完成イメージと比べる（アニメだけ／下に並べる／横に並べる）」（`js/minato-store-view.js` の 83行あたり）の止まった絵を、**動く試作**に置きかえる。その日の港駅の店の本当の計算（`MinatoStoreView.today` の `ev`）から、いまの時刻に近い買いの1人を選んで、試作の絵で再生（次の人へ順に）。できていない部分は止まった絵のまま。絵や設定はファイルを足すだけで増える形（`assets/images/kiosk-scene/` と `data/kiosk-scene.json`）。店の売上・在庫・保存は変えない。画面を開いていないときは描かない（軽さ）。
2. **絵の注文書**：ChatGPT に渡す注文書（`docs/scene-art-order.md`）。大きさ・コマ数・向き・透明の背景・足元の位置・同じ人物に見せるための書き方・ファイル名。まず「人のいない店の背景」、次に人物2〜3人、店員。届いた絵を置くだけで動くようにする。
3. あとはユーザーが絵を足すたびに、Claude が手直しして増やす（レジで1品ずつ読み取る・袋に入れる・ホットスナックを取りに後ろを向く・払い方・品切れでがっかり・棚の品が減る・補充する店員・混む時間の何人も）。

### 2026-11-13 段1・段2（Claude・予定の回）
- **作ったもの**：試作から絵6枚を `assets/images/kiosk-scene/`（webp・合わせて約1.4MB）と `frames.json` に、設定を `data/kiosk-scene.json`（v2）に取り出した。動かす部分は `js/kiosk-scene.js`（`KioskScene`。plan・pose・choose は node でも読める計算だけ、mount・tick は画面）。港駅の店の画面の「完成イメージと比べる」を「動く試作と比べる」に（アニメだけ／下に並べる／横に並べる）。止まった完成イメージは、試作の下の「止まった完成イメージ」ボタンで見られる。
- **だれを見せるか**：その日の本当の計算（`MinatoStoreView.today` の `ev` の buy）から、いまの時刻までに会計を終えた人のうち、まだ見せていない、いちばん新しい人（まだ起きていない人は見せない）。3倍速で再生し、立ち止まるところ（見る・列・食べる）は6秒までに早送り。終わったら次の人へ。いない時間は「次のお客さんを待っています」。
- **見せ方（計算にないものは仮）**：品のジャンルごとに棚の床の点（`spots`）へ、ジャンルごとに1か所（3か所まで）回る。店の中の時間（stay）を歩く・見る・手を伸ばすに分ける。列（前の人数は計算どおり・姿は描かない）・会計（t〜end は計算どおり）・有人レジは横へよけて持ち直す・レンジ・イートイン（立ち席／座る席）・出口。通り道は点と線（`nodes`・`edges`）のいちばん短い道。払い方は決まった乱数（現金30・カード35・スマホ35％・仮）。
- **絵がないもの**：ほかの客層は会社員（男性）の絵で代わり。飲み物は缶コーヒーかスポーツドリンクの絵で代わり、ほかの品は手もとに小さな白い四角。ホットスナック・たばこは棚へ行かない（店員が取る絵はまだ）。新聞・雑誌・日用品・傘は左の壁の棚を横向きに見る（手を伸ばす絵はまだ）。現金・スマホ・座る・食べるはカードや立ち姿で代わり。どれも画面の「まだ絵がない」に出る。
- **会計の位置を直した**：有人レジの前の立つ点を (985,653) → (968,590) に（カウンターのすぐ前。カードが背景の読み取り機に届く）。前の試作が描いていた読み取り機の四角はやめた（背景にある）。列は床の印から左へ横に並び、右（レジ）を向く。
- **置くだけで増える**：背景は `background-empty.webp` があればそちらを使う。人は `people`（grid＝256×384 のマス目・足元 (128,368)・頭から足 315）。ファイルがない絵は代わりで描く。店員（`staff`）は人のいない背景のときだけレジの後ろに描く（`cover` でカウンターの前の面をかぶせる）。マス目の人は、仮の絵を置いて動くのを確かめた（確かめたあと消した）。
- **確かめた範囲**：`tests/kiosk-scene.test.cjs`（買った人506人すべて・時刻が計算どおり・場所が絵の店の中・同じ時刻なら同じ・終わった人だけ選ぶ・res は変わらない）、ほかのテストと lint。ヘッドレス（Playwright）：PC 1280幅で横・スマホ 390幅で下、大きく／店ぜんぶ、有人・セルフ・列・イートイン（立ち・座る）・ホットスナック・雑誌の人の各場面を写真で見た。横にはみ出さない。負荷（スマホ相当・港駅の店）：アニメだけ 仕事 約11％ → 下に並べる 約12％。**スマホ実機は未確認**。
- **気になること**：背景に描きこまれた人（台車の店員・セルフの女性など）と重なることがある（人のいない背景が届けば直る）。家族連れ・カップルなども1人で描く。棚の品は減らない（在庫の同期はまだ）。絵がないファイルを読もうとして、開くたびに 404 が20件ほど出る（動きには関係ない）。

### 2026-11-13 ユーザーの指摘で、動きを人らしく（Claude）
- 指摘：店内で手を大きく振って大股で歩く・ほかの商品を見ない・わき道にそれない・直線に歩いて直角に曲がる・人の前を平気で通る・セルフレジで決済機でないところにかざす・セルフへ行くのに有人レジの真ん前を通る。
- 直したこと（`js/kiosk-scene.js`・`data/kiosk-scene.json`）：
  - **寄り道**（`wander`）：買わない棚の前で立ち止まって見る（0〜2か所・半分は手に取って戻す）。買う棚では4割の人が迷う（手を伸ばしかけて戻す）。時間は店にいた分（stay）の余りからとるので、会計の時刻は計算どおり。急いでいる人（rush）はしない。回る順は入口から近い順。
  - **道**：通り道の点を人ごとに少しずらす（±14）・角を半径40くらいで丸める・背景に描きこまれた人のまわり（`avoid` の円5つ）の外を通る。向きは前後18の先から決める（曲がり道で絵がちらつかない）。
  - **有人レジの前を通らない**：有人レジの前の道（R2→S0）をなくし、セルフへは下の壁ぞい（B0〜B2）から。セルフの列は機械の左下。
  - **セルフレジ**：カードを左へ出す絵をやめ、手を伸ばす絵で画面にふれる形に（立つ位置を、手が画面に届くところへ）。
  - **大股**：歩く速さを 1500 → 1100（絵の上の点/分）にし、足をそろえたコマを長めに見せる。手の振り・歩幅は絵そのものなので、注文書に「店内のゆっくりした歩き（小股・腕はほとんど振らない）」と、セルフで払う絵・見回す絵を足した。
- 確かめ：テスト・lint。ヘッドレスで、70人ぶんの道を背景に重ねた図と、セルフの人の各場面を見た。**スマホ実機は未確認**。
- 残り：背景の人（とくにセルフの女性）と重なる・レンジ待ちをセルフの前でしている・見回す絵はまだつないでいない。

### 2026-11-13 寄り道を「歩きながらちらっと見る」に（Claude・ユーザーの指摘とメモ）
- 指摘：寄り道がふらついて酔っているように見える。言いたかったのは、気になるところ（雑誌など）は、前へ歩きながら顔だけ横を向く・買ってしまいそうなときだけ立ち止まって手に取る、ということ。メモ（缶コーヒーの代わりの品・ついで買い・とりあえず見るコーナー）ももらった。
- 直したこと：
  - **ふらつき**：人ごとに道の点をずらすのをやめた（`wander.jitter` 0）。角を丸めるのと、背景の人をよけるのは残した。買わない棚へわざわざ寄る「寄り道」もやめた。
  - **ちらっと見る**（`attract`・`gaze`）：雑誌の見出し・傘や日用品・冷蔵ケースの新しい飲み物・棚の端の新商品（2か所）・おみやげ・ガムやミントのそばを通ると、まっすぐ歩いたまま少しゆっくりになり、頭の横に「ちらっ」の吹き出し（しっぽは見ている棚のほう）。列に並ぶと、6割の人はレジ横のホットスナックを見る。1人3か所まで。急いでいる人は見ない。顔だけ横を向く絵はないので、吹き出しで代わり（注文書に `walk-look` を足した）。
  - **立ち止まって手に取る**：ちらっと見た棚のうち、ときどき（5〜15％・仮）立ち止まって「気になる…」。奥の棚なら手を伸ばして戻し、横の棚（雑誌など）なら棚のほうを向いて立つ。買わずに戻す。時間は店にいた分の余りから。
  - **回る順**：まず目当ての品（計算のいちばん初めの品）。ついで買いの品は、そのあと近い順。
- 数（ある1日・506人）：ちらっと見た人 313人・立ち止まった人 35人。
- まだのこと（メモから）：缶コーヒーが売り切れで代わりを選ぶ動き（計算の「見て帰った・品切れ」はあるが、買った人の「代わりに選んだ」は記録にない）・カウンターコーヒー（この店にない）。
