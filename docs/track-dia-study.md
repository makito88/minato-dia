# 番線とダイヤの検討（別の会話・ユーザーが 2026-11-17 に貼ってくれた内容のまとめ）

## わかったこと
- 本体は今、駅の番線の数を数えていない（待避できる駅では何本でも同時に待てる）。数を書きかえるだけではダイヤは変わらない。「1本の線路に1本」のきまりを入れると変わる。
- 今のダイヤのままだと、条件に合わない：緑ヶ丘 8分超26回（最長約13分）・大学前 24回（約12分、上りが同時に3本）・川辺 17回（約15分、上下とも同時に3本）。森下・峠は信号所があれば大丈夫。
- 時刻表はそのままで条件を守らせると、140本が5分以上ずれ、編成が35→38。
- **快速を全部14分あと（始発 7:03→7:17）、特急を全部18分あと（7:15→7:33）にずらすと**、条件の違反はゼロ、編成は35→33。待機所は港の留置線に同時2本・温泉の待機線に1本。
- それでも5分以上ずれる普通が33本残る（港発17・温泉発9・中央発温泉行6・中央発港行1。途中で長く待つかわりに始発の駅で待つ形）。普通12分・快速20分・特急30分の間隔がそろっていないため。普通を10分か15分ごとにすると減る見こみ（普通の本数が少し変わる）。
- 車庫：いつもの平日 中央車庫27・港留置線8編成、朝ラッシュ 36・20編成（1本の線路に2編成ずつなら半分の線路）。
- 本線の途中の待避用の信号場・終点の引き上げ線は、あまり効かなかった。

## 出ていた案（ダイヤ作りを楽しく）
きまりチェック（番線・8分・単線）／おまかせ調整ボタン（時刻のずらし方を探す）／間隔そろえのヒント／つまっている所の地図／設備を買う（信号所・待避線・引き上げ線）／ミッション／指令モード（トラブル対応）／臨時列車／作ったダイヤで1日を見る／乗客の声。すすめる順番の案は「きまりチェック・おまかせ調整」→「ミッション」→「指令モード・1日を見る」。

## 2026-11-17 普通の間隔を10分・15分にした場合（ユーザーの頼み）
同じ条件（番線の数・待避駅は8分まで・森下/峠は20分まで・森下〜峠の交換信号所）で、本体の「いつもの平日」を写して試算した。道具は `tools/dia-study.js`（ページの中で動かす。本体のファイルは変えない）。
- 本線の普通（中央⇄港の3つのパターン）の間隔だけを変えた。温泉行の普通（30分ごと）・観光特急はそのまま。
- 快速と特急のずらし方は、それぞれ0〜18分・0〜28分（2分きざみ、150通り）を試して、違反がいちばん少ない組み合わせを選んだ。
- 「守らせると」＝条件を守れるまで、問題の列車の始発を遅らせる（途中で長く待つかわりに始発で待つ）。
- 交換信号所は本体の計算にないので、森下・峠の番線を1本多く（3）数えて代わりにした。

わかったこと
- **普通15分がいちばんかみ合う**。特急30分のちょうど半分なので、追いこしの場所が毎時そろう。条件を守らせても、5分以上ずれる列車は19本・最大15分で、編成は35→29に減る。
  - そのかわり、普通は1時間に5本→4本。1日の乗客は約2%（約3,000人）へり、運賃収入は約180万円／日へるが、走る費用も約170万円／日へるので、差し引きはほぼ同じ。積み残しは今より少ない。
- **普通10分は、かえって合わない**。列車がふえて（+48本）本線がつまり、待避駅の番線と8分の上限が守りにくい。編成も増える（42）。乗客はふえ、積み残しはいちばん少ない。
- 快速20分は、普通15分とも10分とも割り切れない（60分で一回りする）。快速を15分か30分にすると、もっとそろう見こみ（まだ試していない）。
- 乗客・収入の数字は、本体の計算をそのまま使った（その日の条件：平日・晴れ・秋・景気ふつう・イベントなし）。混雑のいちばんひどい列車は、どの案も定員の200%（計算の上限）。
- まだ：朝ラッシュ・観光のダイヤ。本体のダイヤの見本は変えていない。
