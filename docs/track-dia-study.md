# 番線とダイヤの検討（別の会話・ユーザーが 2026-11-17 に貼ってくれた内容のまとめ）

別の会話で、ユーザーと Claude が「番線の数・待機所・停車時間の上限」でダイヤがどう変わるかを、本体の「いつもの平日」（478本・35編成）で試算した。本体のファイルは変えずに、作業用の写しで計算したもの。数字はすべて試算（仮）。

## ユーザーが決めた条件
| 駅 | 番線 |
|---|---|
| 中央 | 5 |
| 大学前・緑ヶ丘・川辺 | 4 |
| 港 | 4 |
| 桜町・新田・森下・峠・温泉 | 2 |

- **森下〜峠のまん中（森下から約2km）に、行き違い用の信号所（交換信号所）**を作る。
- 停車時間の上限：**待避する駅（大学前・緑ヶ丘・川辺）で待つ列車は最大8分**。**森下・峠（と信号所）は各駅停車で最大20分**。

## わかったこと
- 本体は今、駅の番線の数を数えていない（待避できる駅では何本でも同時に待てる）。数を書きかえるだけではダイヤは変わらない。「1本の線路に1本」のきまりを入れると変わる。
- 今のダイヤのままだと、条件に合わない：緑ヶ丘 8分超26回（最長約13分）・大学前 24回（約12分、上りが同時に3本）・川辺 17回（約15分、上下とも同時に3本）。森下・峠は信号所があれば大丈夫。
- 時刻表はそのままで条件を守らせると、140本が5分以上ずれ、編成が35→38。
- **快速を全部14分あと（始発 7:03→7:17）、特急を全部18分あと（7:15→7:33）にずらすと**、条件の違反はゼロ、編成は35→33。待機所は港の留置線に同時2本・温泉の待機線に1本。
- それでも5分以上ずれる普通が33本残る（港発17・温泉発9・中央発温泉行6・中央発港行1。途中で長く待つかわりに始発の駅で待つ形）。普通12分・快速20分・特急30分の間隔がそろっていないため。普通を10分か15分ごとにすると減る見こみ（普通の本数が少し変わる）。
- 車庫：いつもの平日 中央車庫27・港留置線8編成、朝ラッシュ 36・20編成（1本の線路に2編成ずつなら半分の線路）。
- 本線の途中の待避用の信号場・終点の引き上げ線は、あまり効かなかった。

## 出ていた案（ダイヤ作りを楽しく）
きまりチェック（番線・8分・単線）／おまかせ調整ボタン（時刻のずらし方を探す）／間隔そろえのヒント／つまっている所の地図／設備を買う（信号所・待避線・引き上げ線）／ミッション／指令モード（トラブル対応）／臨時列車／作ったダイヤで1日を見る／乗客の声。すすめる順番の案は「きまりチェック・おまかせ調整」→「ミッション」→「指令モード・1日を見る」。

## まだ決まっていないこと
- 本体のダイヤを変えるか（快速14分・特急18分ずらし、または普通の間隔を変える）。
- 本体に「1本の線路に1本」のきまりを入れるか（まず別のページで試作する案だった）。
