# 配送会社とセンターの倉庫

（2026-11-09 に作った。入口は [README](../../README.md)）

## 会社
売店（みなとスタンド）・センター（川辺ロジスティクス）・工場（港浜フーズ）・配送会社（みなと川運輸）は、みなと川グループの別々の会社です。よその会社として、運送の港浜急送と、問屋のみなと卸があります（`data/companies.json`。名前はすべて架空）。トップの「きょうの沿線」に、4つの会社の窓があります。

## 配送会社（みなと川運輸）
- トップの「配送会社」の窓、または「店舗」→「配送会社」から開きます。
- 工場→センターの定温トラック2台と、センター→店のトラックA・B（1日3便）を、自社便として走らせます。
- 追いかけ便（工場が遅れた夜）と、トラックに積みきれない便の応援は、他社（港浜急送）に頼みます。
- 画面：トラックごとの1日の帯（行きと帰り・いまの時刻・遅れ）、便ごとの積んだ量（かご車）・距離・運転の時間・費用・運賃、きょう／きのう…の切り替え。
- 費用（燃料・運転手・トラックの持ち費）と運賃は仮（`data/haiso.json`）。いまは店が1つなので、トラックはほとんど空で、配送会社は赤字です。

## センターの倉庫
- トップの「センター」の窓、または売店の「荷物の行方」タブから開きます。
- 飲み物・お菓子・日用品・冷凍のホットスナックは、倉庫の在庫までしか店に届きません。問屋（みなと卸）へは週2回、センターのおまかせで発注します（次の運行日の朝に着く）。
- 画面：棚ごとの在庫の棒（次に着く数・次の入荷までに出る見込み）、足りなくなるおそれ・薄いの印、この先1週間の発注と入荷、きょう店へ出す数、発注の記録。

## お金の流れ
- トップの「きょうの沿線」のいちばん上の1行（グループのもうけ）、または「店舗」→「お金の流れ」から開きます。
- 品物が動くと、お金は逆向きに流れます。売店→センター（仕入れの代金）、センター→工場（工場の品の代金）、センター・工場→配送会社（運賃）。給料・燃料・問屋・家賃などは「外へ」。
- 画面：グループのもうけ（お客さんから − 外へ）、4つの会社のカード（入った・出た・もうけ）、お金の流れの図。請求書の一覧は折りたたみの中。きょう（見込み）／きのう／7日の合計。
- 値段の決まりは仮（`data/money.json`）。保存は1日のまとめだけ（`dia-money`・35日）。
- 「店を増やしたら（試算）」：この日の店と同じ店が、同じトラックの道に1〜12店ふえたら、配送会社・センター・グループがいくらになるか。配送会社の収入＝店に寄った回数×1,800円＋かご車×350円＋工場→センターのかご車×900円（仮）。センターの決まった費用（1日2万円・仮）は店の数で分け、売店は便ごとにセンターフィー（1,500円・仮）を払う。
