## 保存と引き継ぎ
ヘッダーの「保存・引き継ぎ」から開きます。ゲームはふだんからこの端末のブラウザに自動で保存されています（`dia-` で始まる項目：運転パターン・この日の条件・沿線暦・リサーチ・売店など）。ここでは、それをまとめて扱います。

- **一時保存**：いまの状態を、この端末の中に3つまで取っておけます。「戻す」と、その時点の状態に置きかえてページを読み直します。
- **別の端末へ引き継ぐ**：いまの状態を縮めて「引き継ぎコード」（MD1. で始まる文字）にします。コピー、ファイルに保存、リンク（`…/#load=コード`）のどれかでスマホなどへ送り、向こうの「引き継ぎを読み込む」に貼りつけるかファイルを選びます。リンクなら開くだけで確認が出ます。読み込むと、その端末の状態は置きかわります。サーバーには何も送りません。
- 自動で同期はしません。パソコンとスマホを行き来するときは、そのつど引き継ぎコードを作って送ってください。
- 仕組みは `js/save.js`。

## 留守のあいだ
このゲームにはサーバーがないので、ページを閉じているあいだは何も動きません。そのかわり、開いたとき（スマホで裏から3分以上たって戻ったときも）に、前に見ていた時刻から何運行日たったかを数え（区切りは日本時間の朝4:30）、進めなかった運行日を1日ずつまとめて進めます。沿線暦・売店・リサーチがいっしょに進み、終わると「留守のあいだに○運行日 進みました」とまとめ（日ごとのお客さん・売上・損益）が出ます。

- 最後に見ていた日は、そのときの条件のまま締めます。留守にしていた日の曜日・祝日・季節は実際の暦から、天気は立川市のその日の1日の天気から決めます。
- 天気は、運行日ごとに最初に取れた「1日の天気」を `dia-wxlog` に覚えて、あとから変えません（祝日は `dia-holidays`）。どちらも引き継ぎコードに入るので、PCとスマホで同じ天気になります。天気が取れなかった日だけ、日ごとに決まった乱数の天気にします。
- **シフトは1時間ずつ**（6時〜23時）組めます。1日に入るなら合わせて3時間以上（足りない日は休み）。中抜けは1日1回までで、ある日はやる気が下がります。6時間を超える日は45分、8時間を超える日は60分の休憩があり、そのあいだは店にいません（給料なし）。設定は `data/kiosk.json` の `crew.hourly`。「おまかせ」は今までどおり朝・昼・夕方・夜の区切りで組みます。
- **社会保険**：週のシフト（平日5日・土曜・日曜祝日で数える）が20時間以上で、学生でない店員が入ります（2か月を超えて働く見込みは全員ある扱い。設定は `data/kiosk.json` の `crew.insure`）。お店は給料と交通費の約15.5%を払います。
- **売店の時計はいつも本当の時刻（×1）**です。ダイヤの時計の速さとは関係ありません。同じ引き継ぎコードを入れて同じ日に開けば、PCとスマホで同じ結果になります。片方で棚割り・値段・仕入れを変えたら、もう片方へは引き継ぎコードで移してください（サーバーがないので自動ではそろいません）。
- 留守のあいだは棚割り・値段・仕入れを変えられないので、最後の設定のまま営業したことにします。
- まとめて進めるのは最大14運行日まで。
- 同じ日のうちに開き直したときは、日は進まず、時刻だけ今に合います（売店はその日の朝からいままでの分が見えます）。
- 仕組みは `js/away.js`。開発者ツールの `minatoAway.test(3)` で、3日留守にしたときの動きを試せます。

### 書き出しの声かけ（2026-11-09）
- ブラウザの保存は、端末の買い替えやデータの削除、しばらく開かないこと（とくに iPhone の Safari）で消えることがあります。
- 最後に引き継ぎコードを書き出してから14日たつと（まだ一度もないときも）、画面の下に小さく知らせます。「あとで」を押すと3日出しません。
- 「保存・引き継ぎ」の画面のいちばん上に、この端末の保存の大きさ（ブラウザの上限のおよそ何%か）と、大きいものが出ます。6割をこえたら知らせます。
