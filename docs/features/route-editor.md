## 路線のお絵かき帖（第1段・試作）
トップページの「沿線」→「路線を描く」、または `route-editor.html` を開きます。沿線おさんぽマップの上に、道路・停留所・路線を自由に描けます（地図の外の海や空にも描けます）。
- 左の道具：動かす（V）・道を描く（B、なぞる）・点をつなぐ（P、押していく。2回押しで終わり）・停留所（S）・路線（L、停留所を順に押す）・地図を動かす（H）。
- 道は途中から枝分かれでき、重なると交差点ができます。「動かす」で点や道を引っぱると形が変わり、点を重ねるとまとまります。
- 下の棚で種類を選び、「✎ 見た目」で色・太さ・ふち・点線・光などを変えられます。種類は「＋ 種類」で自由に足せます。
- 右上「路線」で表示の入り切り・名前・止まる停留所・本数と始発/終発、「…」で画像（PNG）・書き出し/読み込み（JSON）・例を描く。
- 2本指で拡大・移動、マウスはホイール。Ctrl+Z で元に戻す。保存はブラウザ（`dia-routes`。引き継ぎコードに入ります）。設定は `data/routes.json`、計算は `js/route-core.js`、画面は `js/route-editor.js`。

## 地図で走らせる（第2段・2026-11-12）
- 描いて保存した路線は、メインの地図（`index.html`）の「バス・配送」の層で、時刻どおりに走ります（見た目だけ。乗客や売店の計算は変わりません）。
- 本数・始発・終発・往復から1日の便を作り、道の長さと乗り物の種類（バス・トラック・船・飛行機）ごとの速さで動きます。夜をまたぐ便（例：23:10〜0:40 の深夜バス）も走ります。
- 停留所には「止まれる台数」があります（停留所を選ぶと下の棚で −／＋。真ん中を押すと種類のふつうに戻る）。空いていなければ手前で待ち、2台以上止まれるところは前後に並びます。道の上でも前の車に近づきすぎると速度を落とし、追い越しません。船は岸壁ごとに1隻。
- 乗り物を押すと、路線名・どこから・どこへ・次の停留所と何時着・遅れ（○分遅れ）の小さなカード。
- 夜（17:20ごろ〜5:50ごろ）は、バス・トラックは前が白・後ろが赤、船は赤・緑・白の航海灯、飛行機は点滅灯。
- 「点をつなぐ」は、PC の右クリックでも終われます（右クリックした場所には点を置かない）。
- 地図の1日は 4:30〜26:00 なので、2:00〜4:30 の便（例：工場→センター 3:05）は地図には出ません。
- 計算は `js/route-run-core.js`、絵は `js/route-run.js`、決まり（速さ・止まる分・台数・車の間）は `data/routes.json` の `run`。

## イベントを置く（第8回・2026-11-14）
- お絵かき帖の左の道具「イベント」（E。`route-editor.html#event` で、はじめからイベントの層）。地図の下に細い**暦の帯**が出て、選んだ日の吹き出しだけが地図に出ます（ほかの日のものは小さな点）。‹ › で1週ずつ、「きょう」で今の運行日に。
- **置く**：地図を押すと、選んでいる日にイベントが置かれ、右（スマホは下）にシートが開きます。吹き出しを引っぱると動き、**近くの駅に自動で結びつきます**。Delete で消す。
- **シート**：印（種類で分けた絵文字の一覧・言葉で探す・最近使ったもの・合うものがなければ「金の文字」で1〜2文字）、種類（ふちの色は種類で自動・「自由な色」で変えられる）、大きさ（ふつう・大きめ）、日とくり返し（一度だけ・毎年・毎週）、時間、画像（絵や写真。横480の JPEG に小さくして保存。なくてもよく、なければカードに地図のその場所が出る）、メモ、効き目（乗客・売店で売れやすい品。なくても置ける）。
- **一覧**：種類・駅・月でしぼれます。押すとその日に移ってシートが開きます。
- **ゲームの地図**：「イベント」の層に、その運行日（暦）に合うものだけが、時刻に合わせて出ます（始まる前はうすく・開いているあいだはゆっくりふくらむ・終わるとさらにうすく）。押すとカード（画像・名前・駅・時間・効き目・「沿線だよりで読む」「売店を見る」「お絵かき帖で直す」）。効き目は**いまは表示だけ**です。
- 保存は `dia-routes` の `evs`（路線と同じ保存・引き継ぎコードに入る。元に戻す／やり直すも路線と同じ）。「ぜんぶ消す」でもイベントは残ります。ここに置くのはユーザーが決めたイベントだけで、季節のできごとは出ません。
- 計算 `js/event-map-core.js`・吹き出しの絵 `js/event-bubble.js`・道具 `js/event-edit.js`・ゲームの地図 `js/event-map-view.js`・設定 `data/event-map.json`。

## 線路を直す（第7回・2026-11-13）
- お絵かき帖の左の道具「線路」（R。`route-editor.html#track` で、はじめから線路の層）。今の線路（本線・川辺で分かれる温泉支線）と2つの車庫（中央車庫・港留置線）が出ます。
- **動かす・曲げる**：線路を引っぱると「曲がる点」ができて曲がります（2回押すと点を足す・点を2回押すと消す）。区間ごとに「なめらか／かくかく」「まっすぐにもどす」。駅の印も引っぱれます（地図の上の位置だけ。キロ程は同じ）。車庫は中を引っぱると動き、右下の角で大きさ、出入りの道は点を引っぱる（最後の点は線路にくっつく）。
- **側線を描く**：地図を順に押して側線や車庫の出入りの線を描く（線路の近くはくっつく。2回押す・「ここで終わる」・右クリックで終わる）。
- 駅の数・順番・つながり・キロ程は変えられません。ダイヤ・乗客・運賃の計算はキロ程だけを使うので、形を直しても数字は同じです。
- 保存は `dia-track`（路線の `dia-routes` とは別。元に戻す／やり直すも別）。「元の線路に戻す」・書き出す・読み込む（JSON）。ゲームの地図は、開き直すと直した形で線路を描き、列車がその上を1両ずつ曲がりながら走ります（駅と駅のあいだは道の長さで割り当て、時刻どおりに駅に止まる）。形の計算は `js/rail-shape.js`、道具は `js/rail-edit.js`。
