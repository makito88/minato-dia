# 沿線のバス網（行事とバスが電車の乗客に効く）

（2026-11-25。入口は [README](../../README.md)）

お絵かきマップ（`assets/images/map_bg.webp`）の上に置いた施設・行事・バス路線を、電車の乗客の数につなげたもの。バスの線と施設は、お絵かき帖の保存（dia-routes）に描き込んで、ゲームの地図の「バス・配送」の層とお絵かき帖に出す（下の「地図とお絵かき帖」）。

## 何が変わるか
- **駅から遠い会場の行事**：会場まで歩ける駅と、バスで行ける駅に、その日の乗り降りの増え方を分けて掛ける。たとえば城跡公園の花火大会は、桜町駅（シャトルバス）に約5割、大学前駅（歩き）と緑ヶ丘駅（南回り線）に約2〜3割ずつ。
  - 季節のできごと：駅を会場のいちばん来やすい駅にしてから（沿線だよりや地図の吹き出しもその駅）、効き目を駅ごとに分ける。便りの「{st}」は会場の名前になる（例：「桜町城跡公園で花見の場所取り」）。
  - プレイヤーが選ぶイベント（`EVENT_DATA`）：会場に行ける別の駅へ、来る・帰る流れの一部を分ける。もとの駅は半分より下げない（例：市民マラソンは緑ヶ丘のほかに大学前へも）。停車時間（ops）は変えない。12件が分かれる。
  - その行事の日にバスの増便があるときは、来る人を1割増しにする（`boost`）。
- **バスが駅に人を運ぶ**：駅を通る系統の本数と、駅から離れた停留所の割合から、その駅に乗り降りする人を少し増やす（約1〜1.7%。平日と土休日で本数が違う）。
- **電車と並ぶバス**：中央〜緑ヶ丘（南回り線）・大学前〜緑ヶ丘・緑ヶ丘〜川辺（中の橋経由）・川辺〜新田・川辺〜森下など、同じ2駅を結ぶ系統があると、その2駅の間の乗客を少し減らす（最大2%）。
- **新しい季節の行事 26件**：今回つくった行事（城跡公園の花火大会・花の丘フェスタ・みなと踊り・万灯みこし・八幡宮の例大祭など）を、季節のできごととして足した。名前と場所はすべて架空。

## 地図とお絵かき帖（2026-11-25 追加）
- ゲームを開くと、お絵かき帖の保存にまだ描き込んでいなければ1回だけ、沿線のバス網（26系統・停留所・道）と施設のピン（82か所・種類「施設」）を描き込む（`js/busnet-doc.js`・`js/route-run.js`）。地図の「バス・配送」の層でバスが時刻どおりに走る。
- お絵かき帖のメニュー「沿線のバス網と施設を描く／消す」。消すのは描き込んだもの（印 `std:'busnet'`）だけで、自分で描いた路線は残る。消したあとは自動では描き込まない。
- 描き込んだものは、ふつうの路線と同じように動かせる・直せる（直しても乗客への効き目は data/busnet.json のまま）。
- **自分で描いたバスの路線も乗客に効く**：駅から0.5km以内に停留所がある路線は、その駅を通る系統として、本数（1日の便数）と、駅から離れた停留所の割合で、駅の乗り降りを少し増やす（2駅以上を結ぶ路線は、その2駅の間を少し減らす）。お絵かき帖で描きかえてゲームに戻ると計算し直す（`BusNet.fromDoc`）。トラック・船・飛行機の路線は数えない。
- 駅のまわりの強さには上限（1駅＋6%）がある。

## ファイル
- `js/busnet-core.js`：計算だけ（`place`・`expand`・`eventFlows`・`table`）。テストは `tests/busnet-core.test.cjs`。
- `data/busnet.json`：停留所（絵の座標）・26系統（本数・通る駅・`feeder`）・行事の日の増便（`extra`）・会場と駅ごとの割合（`venues`）・強さ（`fx`）。数値はすべて仮。
- `data/seasonal-busnet.json`：新しい季節の行事（`data/seasonal.json` と同じ形）。
- `js/busnet-doc.js`：お絵かき帖への描き込みと消し方。`data/facilities.json`：施設82か所（地図の座標）。
- `index.html`：読み込みと、`seasRefresh`・`ensRefresh`・`rateParts`・沿線だよりの便りの4か所と、自分で描いた路線を読む `userBusRoutes`。`data/busnet.json` が読めないときは今までと同じ。

## 割合の決め方
会場から各駅への「行きやすさ（分）」を、歩き（1kmを15分、1.9kmまで）と、バス（待ち＋乗る時間＋停留所まで歩く＋乗りかえ3分）のうち小さいほうで出し、`exp(−分/10)` の重みで上位3駅に分ける（1割未満は切る）。行事の日に増便がある系統は待ち3分で数える。
