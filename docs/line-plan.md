## 絵の作り方（ChatGPT）
1. こちらで**下絵**（線のSVG）を作る：線路・川・海岸・大きな道・駅のホーム・空港・車庫・大学・団地・モール・城跡・田んぼの位置。
2. タイルごとに、下絵の切り抜き＋「描くものの指示」（町のカルテ docs/machi-karte.html の1km圏の数）を渡す。
3. 全タイル共通の決まり：見下ろす角度は今の地図と同じ・光は左上・秋の昼・同じ文面の指示。
4. つなぎ目は重ねた0.5kmでなじませる。角度や色がずれたタイルは描き直す（何回かやり直す前提）。
5. **線路・駅名・電車・トラックは絵に描かない**。ゲームの側で上に描く（絵が多少ずれても位置とキロは正しい）。
- 数は「雰囲気で合う」でよい（団地42棟が30棟に見えても可）。数そのものは町のカルテが正。

## 空港・他社線・車庫
- **空港**：中央駅から西5km・南1km。滑走路は南北2.5km（250マス）。空港のまわりに倉庫・ホテル・駐車場・レンタカー、その外は田んぼと住宅。
  - 中央のビルは高さ約65m（20階くらい）まで（制限表面の円錐表面。5km地点で約65m）。高い塔は描かない。
  - 飛行機の道は空港の北と南（中央のビル街の上は通らない）。南側は海か川にすると自然。
- **他社線**（絵と名前だけ・計算しない・人数は変えない）：西の端から入り、空港駅→中央（乗りかえ）→北へ抜ける。名前は架空（例「県央本線」）。
- 空港へは他社線とリムジンバス（中央駅西口15〜20分）。みなと川電鉄は延ばさない。
- **中央車庫**：中央の西1〜2km・線路の北側へ（今は南側）。出庫の時刻とダイヤは変わらない。
- **港留置線**：今と同じく港の手前・新田側の北。
- 港の先・温泉の先には他社線を描かない。

## 自社のトラックの「いまの位置」
- 時刻：data/center.json・data/haiso.json の便（CenterCore.truckRuns の出発・到着）。遅れた日はその日の計算の到着時刻。
- 道：お絵かき帖の「自社の配送」の線（route-editor の groupRoutes）。
- 電車と同じく「出発から到着までの何割か」で道の上に点を置く。更新は10秒に1回。

## 引っ越し（古い位置→新しい位置）
- 変換は1か所（例 js/map-coord.js）。対象：ST の x,y、depot、お絵かき帖で保存した路線、配送のピン、イベントの吹き出しの位置。
- 保存の形を変えるときは `v` を付ける。古い保存も読めるようにする。
