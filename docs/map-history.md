# 沿線の歴史から考える、いまの地形と町の広がり（年表・2026-11-15）

新しい地図をやり直すときの「つじつま」の元にする年表です。白紙から町を置くのではなく、
**歴史の流れで、どこに・いつ・なぜ町ができたか**から、いまの地図の姿を考えます。

- **【カルテ】**：町のカルテ（docs/machi-karte.html の history・yukari・towns）にすでにある話。変えない。
- **【新】**：今回こちらが考えた案（仮）。ユーザーがよければ、町のカルテにも足す。
- 数字（人口・乗客）はすべて架空。人口は町のカルテの series（千人）。
- 守るもの：今の地図の駅のだいたいの並び・駅ごとのだいたいの乗る人の数・総キロ数（本線21.5km・支線12.9km）。

## 0. 土地の形（人が住む前から）

| 地形 | どうしてできたか | いまの地図に残るもの |
|---|---|---|
| 西の平野 | みなと川の古い流れと、西の小さな川がつくった扇状地 | 中央・桜町・大学前の平らな市街地。空港を置ける広さ |
| みなと川 | 北の山から南の湾へ流れる大きな川。河口は砂がたまって浅く、昔は何本にも分かれていた | 川辺の河川敷（洪水のとき水を逃がす広い河原）、川の東の低い土地（新田の田んぼ） |
| 東の山 | 湾にせまる古い火山の山地。谷に温泉がわく | 森下・峠・温泉。港の背後の急な山 |
| 緑ヶ丘の丘 | 川の西にある低い台地（段丘） | 1970年代まで雑木林と畑。のちのニュータウン |
| 湾 | 東の山に守られた深い入り江 | 港浜の港。西のほうは遠浅の砂浜 |

| 年 | できごと | いまの地図に残るもの |

## 2. 港と鉄道の時代（1868〜1922）

| 年 | できごと | いまの地図に残るもの |

| 1891【新】 | 国の鉄道（いまの**県央本線**）が、西の平野を南北に通る。城下町の家並みをさけて、**城下町の西3kmの田んぼの中**に駅（いまの中央駅）を置く | 県央本線の線路。中央駅が「城下町の外」にある理由 |
| 1895【カルテ】 | 新田の棚田に石の用水路 | 棚田と石の分水口 |
| 1897【カルテ】 | みなと川軽便鉄道が開業。国の駅（中央）から城下町（桜町）・渡し場（川辺）・新田をへて港へ。寺町を切らないよう線路を少し曲げる | 桜町駅のカーブ。本線が、街道より少し南を通る |
| 1900【カルテ】 | 港浜の海岸通りに洋館と商館 | 海岸通り・赤レンガ倉庫（1908） |

## いまの地図にすると（やり直しの下絵で守ること）

1. **町の中心は2つ**：中央（駅前の新しい中心・碁盤の目・ビル）と桜町（城下町・曲がった道・瓦屋根）。見た目をはっきり分ける。
2. **町は鉄道のまわりだけでなく、街道と道ぞいに広がる**：西・北・北東の3本の街道ぞいに、家が細長く伸びる。バイパスぞいに大きな店。
3. **平野の田んぼは「何もない所」ではない**：1〜2kmおきに古い集落と鎮守の森。中央に近いほど、集落のまわりが住宅地になってつながる。
4. **鉄道から離れた大きなもの**：県央本線とその駅の町、空港、高速道路とインター・工業団地・物流センター、太陽光パネル。
5. **川の東は性格がちがう**：川辺は渡し場の宿場町から生まれた町。新田は江戸時代に開いた、まっすぐな区画の田んぼと水路。港の西と南は埋め立ての工場。
6. **山は人が少ない**：森下の集落・峠の茶屋・温泉街だけ。山道は昔の湯ノ谷街道。
7. **駅の並び・乗る人の数・キロは今のまま**：中央（1日5万7千人）がいちばん大きく、新田・森下・峠は小さい。

## 【新】の案のうち、町のカルテとのつじつまを確かめたいこと

- 1891年の国の鉄道（県央本線）：中央駅が城下町の外にある理由になる。県央本線は計算には入れない（絵と名前だけ）。
- 1912年に県庁が中央へ移る：今の町のカルテでは、県庁は中央にある。
- 2005年の合併：みなと川市の186km²に田んぼや山が入る理由になる。
- 1996年の川辺のモール、1985年の高速道路、1964年の空港。
