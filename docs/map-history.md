# 沿線の歴史から考える、いまの地形と町の広がり（年表・2026-11-15）

新しい地図をやり直すときの「つじつま」の元にする年表です。白紙から町を置くのではなく、
**歴史の流れで、どこに・いつ・なぜ町ができたか**から、いまの地図の姿を考えます。

- **【カルテ】**：町のカルテ（docs/machi-karte.html の history・yukari・towns・stations）にすでにある話と数字。変えない。
- **【新】**：今回こちらが考えた案と数字（仮）。ユーザーがよければ、町のカルテにも足す。
- 数字はすべて架空。人口は町のカルテの series（各年の値）。乗客は「みなと川電鉄の全駅の1日の乗車」。
- 守るもの：今の地図の駅のだいたいの並び・駅ごとのだいたいの乗る人の数・総キロ数（本線21.5km・支線12.9km）。
- 他社線（県央本線）・バス・空港・フェリーの数字は、絵と町の勢いを考えるためのもの。ゲームの計算（乗る人の数・運賃・ダイヤ）には入れない。

## 0. 土地の形（人が住む前から）

| 地形 | どうしてできたか | いまの地図に残るもの |
|---|---|---|
| 西の平野 | みなと川の古い流れと、西の小さな川がつくった扇状地。東西およそ12km【新】 | 中央・桜町・大学前の平らな市街地。空港を置ける広さ |
| みなと川 | 北の山から南の湾へ流れる大きな川。長さ約62km【新】。河口は砂がたまって浅く、昔は何本にも分かれていた | 川辺の河川敷（洪水のとき水を逃がす、幅300〜400mの河原）、川の東の低い土地（新田の田んぼ） |
| 東の山 | 湾にせまる古い火山の山地。いちばん高いひのき山は1,214m【新】。谷に温泉がわく | 森下・峠・温泉。港の背後の急な山 |
| 緑ヶ丘の丘 | 川の西にある低い台地（段丘）。まわりより20〜30m高い【新】 | 1970年代まで雑木林と畑。のちのニュータウン |
| 湾 | 東の山に守られた深い入り江（みなと湾）。湾の中に小さなひのき島【新】 | 港浜の港。西のほうは遠浅の砂浜 |

## 1. 城下町と街道の時代（〜1868年）

| 年 | できごと | いまの地図に残るもの |
|---|---|---|
| 1600年ごろ【新】 | 川の西の微高地に城が築かれ、城下町ができる（いまの桜町）。石高12万石ほどの藩 | 城跡のお堀・武家町の四角い区画・曲がりくねった町人町の道 |
| 1650【カルテ】 | 寺町通りにお寺が9つ並ぶ | 寺町の石畳と白い土塀 |
| 江戸時代【新】 | 城下町から3本の**街道**が出る：①西へ（平野の村々をぬけて隣の国へ）②東へ（川を渡し舟でこえ、海ぞいに港浜の漁村へ）③北東へ（川ぞいをさかのぼり、峠をこえて湯ノ谷の湯治場へ） | **いまの国道・県道は、この街道の上**。道ぞいに古い家並みが細長く続く |
| 江戸時代【新】 | 川の渡し場に宿場ができる（いまの川辺）。旅籠が20軒ほど | 川辺の古い町並み・渡し場の跡 |
| 1700年代【新】 | 河口のぬかるみを藩が開いて田んぼにする（**新田開発**。地名の「新田」はここから）。開いた田んぼは約600ha | 新田の、まっすぐな区画の田んぼと水路。区画の角ごとに小さな集落 |
| 江戸時代【新】 | 平野のあちこちに農村。1〜2kmおきに、屋敷林に囲まれた集落と鎮守の森。いまの地図の範囲に、村が80ほど | **田んぼの中に散らばる集落**（いまは住宅地に飲みこまれたものも多い） |
| 江戸時代【新】 | 湯ノ谷は湯治場（宿10軒ほど）、森下は木こりの村、港浜は小さな漁村 | 温泉の古い湯屋・森下の杉林・港の古い漁師町 |

> **1890年の人口【カルテ】**：みなと川 10.5万・港浜 1.4万・新田 2.3万・緑野 1.6万・森下 0.8万・湯ノ谷 0.5万人。城下町の名残で、みなと川だけが大きい。

## 2. 港と鉄道の時代（1868〜1922）

| 年 | できごと | いまの地図に残るもの |
|---|---|---|
| 1871【新】 | 城下町に県庁が置かれる。はじめは城の近く | 桜町の古い役所の建物（郷土資料館） |
| 1889【カルテ】 | 港浜で近代港の築港。技師ファン・デル・ブロークが、川の流れを変える堤防を築く | 河口の長い堤防・港の防波堤 |
| 1891【新】 | 国の鉄道（いまの**県央本線**）が、西の平野を南北に通る。県の中を通る長さ128.4km。城下町の家並みをさけて、**城下町の西3kmの田んぼの中**に駅（いまの中央駅）を置く。はじめは1日6往復の蒸気列車 | 県央本線の線路。中央駅が「城下町の外」にある理由 |
| 1895【カルテ】 | 新田の棚田に石の用水路 | 棚田と石の分水口 |
| 1897【カルテ】 | みなと川軽便鉄道が開業。**中央—港 21.5km・駅5つ・蒸気で75分**。国の駅（中央）から城下町（桜町）・渡し場（川辺）・新田をへて港へ。寺町を切らないよう線路を少し曲げる | 桜町駅のカーブ。本線が、街道より少し南を通る |
| 1900【カルテ】 | 港浜の海岸通りに洋館と商館。乗客は**1日3千人** | 海岸通り・赤レンガ倉庫（1908） |
| 1900〜20【新】 | 中央駅の前に、旅館・問屋・銀行が集まり、新しい町ができる。県庁も駅の近くへ移る（1912）。港の船の出入りは年1,200隻ほどに | **町の中心が、城下町（桜町）から駅前（中央）へ移る**。中央と桜町のあいだの3kmが、だんだん家でうまる |
| 1912【カルテ】 | 湯ノ谷鉄道（**川辺—温泉 12.9km**・駅4つ）が開業。峠の鉄橋（142m・1911） | 温泉支線・峠の赤い鉄橋 |

> **1920年**：人口 みなと川 16万・港浜 3.8万【カルテ】。電鉄の乗客 1日1.2万人、中央—港 48分（1923）【カルテ】。

## いまの地図にすると（やり直しの下絵で守ること）

1. **町の中心は2つ**：中央（駅前の新しい中心・碁盤の目・ビル）と桜町（城下町・曲がった道・瓦屋根）。見た目をはっきり分ける。
2. **町は鉄道のまわりだけでなく、街道と道ぞいに広がる**：西・北・北東の3本の街道ぞいに、家が細長く伸びる。バイパスぞいに大きな店。みなと川市の人の8割は駅の1km圏の外に住む。
3. **平野の田んぼは「何もない所」ではない**：1〜2kmおきに古い集落と鎮守の森。中央に近いほど、集落のまわりが住宅地になってつながる。
4. **鉄道から離れた大きなもの**：県央本線とその3駅、空港、高速道路とインター2か所・工業団地・物流センター、太陽光パネル。
5. **川の東は性格がちがう**：川辺は渡し場の宿場町から生まれた町。新田は江戸時代に開いた、まっすぐな区画の田んぼと水路。港の西と南は埋め立ての工場。
6. **勢いの差を絵に出す**：緑野市（ふえている）は新しい家と空き地の造成。新田・森下・湯ノ谷（へっている）は古い家と、使わなくなった田んぼ・太陽光パネル。
7. **山は人が少ない**：森下の集落・峠の茶屋・温泉街だけ。山道は昔の湯ノ谷街道。
8. **駅の並び・乗る人の数・キロは今のまま**：中央（1日5万7千人）がいちばん大きく、森下・峠は千人台。

## 【新】の案のうち、町のカルテとのつじつまを確かめたいこと

- 1891年の国の鉄道（県央本線・128.4km）と、1987年の民営化（県央旅客鉄道）。中央駅が城下町の外にある理由になる。
- 1912年に県庁が中央へ移る：今の町のカルテでは、県庁は中央にある。
- 2005年の合併：みなと川市の186.4km²に田んぼや山が入る理由になる。
- バス会社の内わけ（市バス36・みなと交通28）は、カルテの「駅にかかわる系統69」と別の数え方（市全体の路線数）。
- 空港（年104万人）・フェリー（1日10往復）・高速道路。ゲームの乗る人の数には入れない。
